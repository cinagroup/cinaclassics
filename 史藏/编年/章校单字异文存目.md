# 章校单字异文存目

《资治通鉴》胡三省注本所附章钰校记，凡五百零六条（〔章：…〕为记）。其中明指单字异文者七十四条，皆记十二行本、乙十一行本、孔本等旧本与此本用字之异，非本书之讹。此目专录之，以备后人据以裁。

立目之由：章校之例，凡异文只著某本作某，不判是非；其字或两通，或各有所本，与本库（四库本）及点校本之从违并列，可以见版本源流，不可以径改正文。

表列五事：一、章校原记（底本字→异本字）；二、注文锚（章校所在注文之上十六字，以为定位）；三、本库用字（正字与异字之计数）；四、点校本用字（同）；五、备注。计数以今本实测，异字作「—」者为章校只著某本正作某、未指底本原字。

## 附：章校五百零六条之分类

章校块五百零六条，依其措辞分四类（一类之中有兼具二类者，故合计多于五百零六）：

| 类别 | 措辞之例 | 条数 |
|---|---|---|
| 增字 | 「十二行本『莫』下有『敢』字；乙十一行本同」 | 一百八十四 |
| 脱字 | 「十二行本无『难』字；乙十一行本同」 | 十七 |
| 倒乙 | 「十二行本，二字互乙」 | 二百六十 |
| 单字异文 | 「十二行本『王』作『周』」 | 七十四 |
| 其他（章校按语、版本考、字书引证之属） | 「乙十一行本正作『狐』」 | 四十一 |

增字一类，所增之字以虚字为多（者五见、之四见、出二见、余二见、为二见），与全库「点本截锚所见本库脱字四百零三形多为之／以／其／而虚字」之判正合。脱字一类可抽者十六形，其字在本库皆有（count 不为零），是章校所见底本无而四库本有，属版本出入，非本库脱漏。

**此目之用**：三类之数既定，则知章校所记，十之七为增脱倒乙（版本篇幅之异），十之一五为单字异文（字形之异），其余为按语。凡后人欲据章校改本库者，当先辨其入于何类：入增脱者涉字数，违「一字换一字」之限；入单字异文者涉两通，无可绳之证；皆不可径改。
