# 注本讹误登记

本库《资治通鉴四库.md》为四库本，异体字多；对校本《资治通鉴注.md》为标点本（正文＋胡三省注＋考异），
其注文层经 OCR 与翻刻，讹形成族，方向与本库往往互异。r1291～r1300 十轮勘校中所见注本讹族，
逐族登记于此，以为日后校注本、定对校方向之用。

**登记原则**

1. 只登记已由本库内部计数或外部他书证实之族，一族一条，不列未定者。
2. 「注本讹形」指注本在用字上系统替换本库正字；「本库正字」指本库通行且经判据确证之字。
3. 处置栏「不改」者，谓本库不改；注本之讹留待校注本时一并料理。
4. 零星单条附于族表之后，标明位号。
