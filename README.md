# Cinaclassics · 中华古籍全文库

本项目收录 **15,000 余部** 中国古代文献，全部为 **Markdown（.md）格式、UTF-8 编码**，按传统经史子集之外的「十藏」体系分类组织，便于在线阅读、全文检索与二次开发（如构建古籍语料库、全文数据库、检索系统等）。

本项目文本源自「殆知阁古代文献」数据集，在其基础上整理为 Markdown 格式。

## 如何使用

**在线阅读**：直接在 GitHub 网页上浏览目录并点开任意文件即可阅读。

**全文检索**：
- 检索正文内容：使用页面顶部的搜索框，输入关键字后选择「In this repository」在本仓库内搜索；
- 按书名/文件名查找：在仓库主页按 <kbd>t</kbd> 键（或点击 **Go to file**），输入标题快速定位文件。

**下载**：点击仓库右上角绿色的 **Code** 按钮，选择 **Download ZIP**；或使用 git 克隆：

```bash
git clone https://github.com/cinagroup/cinaclassics.git
```

> 注意：仓库体积约 2 GB，建议使用桌面端浏览器下载；网络不稳定时可多次尝试或分段克隆。

**本地检索**（推荐，速度快）：

```bash
# 在所有文献中全文搜索
grep -r "关键词" --include="*.md" .

# 或使用 ripgrep（更快）
rg "关键词" -g "*.md"
```

## 格式说明

- 所有文件为纯文本 Markdown，正文未添加 Markdown 标记，可直接当作纯文本处理；
- 编码为 UTF-8，换行符为 CRLF（Windows 风格）；
- 原始数据为 txt 格式，2026 年 9 月已整体更名为 .md。
