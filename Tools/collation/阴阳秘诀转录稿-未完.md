== 0005 堪輿斷語（一，密行） ==
「（楊州）坤方三十里東（泰?）山下仙鶴抱卵形，銀河天台山人（仙?）舞袖，巽卯來龍起伏聚大川大江合流之間，特起巽峰山吉（?），降落巽來巽作巳坐，左右水會辛方，龍長虎短，明堂廣大江灣環，東小白耦（?）足北三登四名山中，三十八將才雄，萬吋材將相一品之地。楊州。」
「癸方二十里許西山，下去帶形似帽，鶴飛上天格，佛國山小祖超（?）山申（?）祖懸燈出百餘里，丑艮未龍三番起落，巽辰逆四殘（?）山進脉平地渡峽，雄起內龍虎短田挾穴巽丁，得甲破外堂廣活，巽得卯辰水九曲朝堂，五癸破傍城雄圍，西寒微山東縣燈山南三角止馬嵯乾甘岳，巽龍巖坤高靈艮魚登，八大名山周二百餘里，三十八峰雄圖，五重盤龍顧祖山水岫結，文科多出雄州巨牧將相賢人血食之地。癸方五十里飛鳳歸巢形抱郊桑田，龍顧祖格送山小祖超（?）山申（?）祖，水遶山太根百餘里，艮卯巽丁行龍屈田以未還入巽辰，奔走起巽作腦辛兌八首鳳頭結尖四坐，巽得丑破水纏玄武，內堂平正百谷水同聚朝堂，龍虎拱穴外堂平圓，龍虎長田結句（穴?），西甘岳東白雲南。」
（按：按方位起例之地局斷語——坤方、癸方各一局，仙鶴抱卵、鶴飛上天、飛鳳歸巢諸喝形；「楊州」疑為地名人名目或「楊州」地名結穴語；行草密行兼霉漬，讀多存疑，此冊通例。）

== 0006 斷語（二，密行） ==
「水岳止寶蓋乾岫嵯巽壬子坤佛國艮佛舞山，八大山周回二百餘里，城郭雄圍五重，三十八將卓立，將相之地。○癸方六十里許天磨山，仙女驕空形，花盤案，月出雲中格。天磨小祖五賢中祖懸燈，大祖百餘里，艮坎癸行龍，來勢龍飛鳳舞，登天飛騰，艮亥遠逶（?）以來，雄盤天磨山，治布大帳，坎㟝雲頭，束脉頓超上聚結穴，后山出角窩中微乳，子坐（?），堂方圓，龍虎短回，艮卯亥庚水丙方合流，巽辰流左右，龍虎起伏長田結局。之外左大川右大江合流下入海，北水漂山南德堂，西三角東龍門乾道峰坤清淨巽無甲艮黃鶴，八大名山三百餘里，三十粉黛八百烟花羅列，文章文料，州牧將相封君之地。○申方三十五里許艮來山下將軍擊鼓岫洞形，發旗屯軍集騎，龍上天格，艮卯巽來龍，陰龍陽穴，艮脉甲坐辛亥淨水破巽辰流，甲卯浮水長流，坤方西外明堂平圓，龍虎結局，穴處龍額也。東懸燈南水岳西佛國北王方，四大名山周回百餘里，城郭雄圍重疊，三十八將文星尖秀，文武高靈。巽三角乾患陰艮佛國坤見遠，八大山周回百餘里，雄圍五重，三十八將高聳，百子千孫，文武科料相封君之地。○申方四十里許高靈山盤龍形，望海案，伏兇望月格，百餘里艮卯來龍分派九龍，從崋（華?）勒（勤?）第三中大龍五星聚講，三台降落，四面大野之中自作結局。」
（按：承 0005 之例，癸方天磨山仙女驕空形、申方將軍擊鼓岫、高靈山盤龍形三局；「三十粉黛八百煙花」「三十八將」「五星聚講」皆堪輿套語；行草密行，辨字多疑。）
