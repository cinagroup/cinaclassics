== 0005 堪輿斷語（一，密行） ==
「（楊州）坤方三十里東（泰?）山下仙鶴抱卵形，銀河天台山人（仙?）舞袖，巽卯來龍起伏聚大川大江合流之間，特起巽峰山吉（?），降落巽來巽作巳坐，左右水會辛方，龍長虎短，明堂廣大江灣環，東小白耦（?）足北三登四名山中，三十八將才雄，萬吋材將相一品之地。楊州。」
「癸方二十里許西山，下去帶形似帽，鶴飛上天格，佛國山小祖超（?）山申（?）祖懸燈出百餘里，丑艮未龍三番起落，巽辰逆四殘（?）山進脉平地渡峽，雄起內龍虎短田挾穴巽丁，得甲破外堂廣活，巽得卯辰水九曲朝堂，五癸破傍城雄圍，西寒微山東縣燈山南三角止馬嵯乾甘岳，巽龍巖坤高靈艮魚登，八大名山周二百餘里，三十八峰雄圖，五重盤龍顧祖山水岫結，文科多出雄州巨牧將相賢人血食之地。癸方五十里飛鳳歸巢形抱郊桑田，龍顧祖格送山小祖超（?）山申（?）祖，水遶山太根百餘里，艮卯巽丁行龍屈田以未還入巽辰，奔走起巽作腦辛兌八首鳳頭結尖四坐，巽得丑破水纏玄武，內堂平正百谷水同聚朝堂，龍虎拱穴外堂平圓，龍虎長田結句（穴?），西甘岳東白雲南。」

== 0006 斷語（二，密行） ==
