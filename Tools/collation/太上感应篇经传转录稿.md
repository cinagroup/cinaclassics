== 0002 序文（末）＋朱朝卿自叙刻书缘起 ==
「性惟均，有感而思善，是謂本初之念；不琢先天之元，天自降康。有敢而為惡，是謂喪初之慮，盡為後習之誤，天必降殃，必然之理。語有曰：福禍惟人自召，感應捷於影響。故帝君撰為此篇遺世，是欲人人盡出迷途、登之覺路，造斯世斯民于大道之域也。茲於往事之感應未暇殫述。適卿陝（?）於丙辰歲，染以痰火，坎凜（?）刀圭无靈，計无所之，乃皇蒼穹首誓之曰：苟得少瘥，願捐微俸授梓剞劂，感應篇章章百簡以新。帝君救諸一切苦惱真意，為通顯編氓悍警（?）者之一勸。念激自衷，感而遂應，於是稍稍平復，竟爾康莊，寧非帝君神力哉！帝君在漢在唐皆至名碩，前身後化，歷功于國（?），徧醒群生。體雖幻化，精靈如在。感應篇什，因緣果報不爽毫芒，誠救病之鍼砭、進善之藥石也，大有補于斯世斯民。卿安敢不序而梓之，以為眾生之一助云。是歲丁巳春王穀旦，唐王孫朱朝卿薰沐叩書。」
（按：序自述丙辰染疾誓愿、捐俸授梓，次年丁巳序成——明刊本可定為萬曆丁巳（1617）前後刻，斷代新證；著錄原僅記「明刊本」。）

「太上感應篇經傳（卷端題）
梓潼帝君救劫寶章
真君曰吾一十七世為士大夫，未嘗雪（虐?）民酷吏；周人之急，濟人之乏，容人之過，憫人之孤，一心如此，聽命于天。今勸世人若如此行，天必降之福：饒一著添子孫之福壽，退一步免除駒（驱?）之易過，忍一言免駟馬之難追，息一怒養身心之精神。
神霄小吏呂嚴（?）曰：精神妙哉非紙載，斯言謹守行之，福佑自天。
梓潼帝君諭敕劫草（?）……貞君（真君?）曰吾道圓通大證真位茲以劫運（?）……晉愍帝永嘉六年壬申歲七月七日（?），軒轅車駕金童玉女持將天兵樂隊旌旗百萬引從待……（下接）」

== 0006 救劫宝章（续）＋四章六行诵法 ==
「……吾（帝君自叙，大字）……一指天池亭車日月停輪飛雲霧上衛黑氣盤結，有駭童子承旨預定善惡。言閱善簿得忠孝五功德陰騭僧行者若干人；閱惡簿得十惡五逆，臣民愚夷，士農工商僧道雜流有為惡者若干人。吾愍劫運之臨，世人造惡无有三萬萬。神兵神將天魔三百萬，飛天神王主之；萬神兵將天魔六百萬，以吾道雷神主之。收取惡人用充劫運，罪罰不遠，惡可哀憐。……」
（四章六行诵法，小字传注）「尊聲赴感太玄救苦天尊、九天應元雷聲普化天尊、玉虛師相玄天上帝金闕化身天尊四位聖號，朔望誦救助劫寶章一，太上感應篇一遍，以消罪愆。尤當遵以六章修行，徒口誦經欲免降懲；名曰傳於世，罪无重愈，不可解。吾今降此經，亦傳於世；蓋善勸行善（?）。其有讀誦此經而不信受、與前信受後有悔心者，仰飛天大神即時收取以充劫數。如有祕藏者不傳此經，其罪維均。各宜省（?）。」（小字传注从略处俟专项覆核）

== 0008 警戒章（续）＋居官章（起）＋感应故事 ==
（第一章主文续，大字）「或倚恃富勢而欺凌小民，或欺德前輩，或口念佛而薄於父母，或貌敬天地而中萌欺詐，或教人興訟而破人家產，或巧妄言語而助人之過，或破人婚姻，或誹謗同類，或播弄是非，或埋藏陰毒——此等罪犯雖可解雪，倘（?）非心康席（?）幾免咎。」
（小字传注故事）
「衢州范元之（?）素貧。拾得金銀一囊於岸，謂其子曰：與其終於溝壑，枉喪性命（?）。於彼岸待之，果見一婦悲泣而至，云夫以（?）婦死易田得銀至此失之。元之卽以釵還婦，分與不受。人多薄之，謂其不能經營生理。元之笑而不答。次年父子登第，至今十二世為二千石。
信州林茂先，才高過人，閉戶自守。有富婦奔之，林曰：男女有別，禮法不容；天地鬼神，羅列森布，何可以此污我。婦慚而退。茂先次日舉登第，第三子皆登第。見聞者各日用戒。」
（第四「居官」章，起）「帝君曰士之居官，以忠為先。今世大異：上而卿相，下而一命，賄賂公行……天震怒……侵民膏血不自肥……處果昭彰，顯報若速。悔心可免灾。官子弟多不報（?），勢位名宦之家多破殁，上天之報昭然，人若不自覺矣。」
