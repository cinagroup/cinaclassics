**过录体例（本稿自定，用于此註解本）**：此书大字正文之外通篇夹双行小注，注密至每行皆有（注音、训释、引经），若正文与注全录，一部之工抵三四部。故本稿采「**正文全录、注择要**」之例——大字正文逐字照录；小字注则录其（一）引据经史以证阵数者（如《易大传》《洪范》孔安国、刘歆、朱子诸说），（二）训释关键名物者（如「式，法也」），其余纯注音（如「屬之欲切」）与通训从略，并以〔〕标示注文、以（按）说明取舍。入库时此例一并写入凡例，俾读者知所据。

**体例**：大字正文之外，通篇夹有密集小字注（注音如「屬之欲切」「彙音切」、训释如「寧，安也」「濟，渡也」「式，法也」，并引《书》《诗》《易》及《孙子》以证），为朝鲜谚解以前之汉文註释体。另有朱笔句读、墨笔改字。

== 01L 陣法序 ==
陣法序
陣法自風后握奇以後，諸葛亮、李靖得其遺法，雖因時宜，有八陣、六花之名。陣法：諸葛亮八陣，李靖六花，實本黃帝風后之遺制也。其後變制愈出，李靖演為八陣，飛龍、翔鳥、蛇蟠、天、地、風、雲、龍、虎、鳥、蛇八陣，或傳為奇正四陣。唐太宗以神武定禍亂，乃本其理，則至今天下無有不知其法者，然其要歸亦不外乎風后握奇之八陣而已。其理則至（于今）……
（按：全篇大字正文与小字注交错，注文密布行间，须逐行分辨。）

== 02R 序续 ==

余河崙〔崙，安而勿忘危也〕、卞季良、河敬復、鄭欽之、鄭招撰集陣說，以為教士之常式〔式，法也〕，然河崙等所撰但撮古文而條畫有未盡，恭惟我（主上殿下）……

定陣法〔番漢之勢，國語謂胡馬奔衝，此奇兵；按漢兵唯馬兵強弩騎兵，正兵角此，求之於勢，不責於人，故能擇人而任兵，善用兵者……〕

== 03L 序续 ==

== 04R 序续 ==

之終言，孔子集群聖之事而為一大聖〔哲也，立弘規於後葉。弘，大也；規，法也。雖天縱之也，獨作樂者，集群音之小成而為一大成〕……
特賜顧問〔漢書：博士議郎掌顧問應對也。凡所政治曰業。顧，視也〕……
臣之愚癡，何足以贊揚一策〔不慧也，贊，助也；揚，明也；策，謀也〕，但奉……

== 04L 序末（纂修官衔名） ==
……成算出納〔休，美也。唐太宗征高麗，長孫無忌曰：陛下聖謀，諸將奉成算而已。籌，畫也；休，美也〕……
親行陣，九出奇制勝，皆上稟聖算〔曰：敢對揚天子之休命。揚，天也。於是〕……
命【臣】與工曹判書【臣】鄭麟趾、中樞院使【臣】金孝誠、兵曹參判【臣】黃守身、僉知中樞院事【臣】趙由禮、護軍【臣】金有銑、兵曹正郎【臣】宋處儉、守校書校理【臣】權擥、承文院正字【臣】洪允成會議，於兵曹定之。

== 05R 正文卷首：以河圖洛書之數立陣 ==
余【臣】存之【臣】諱【臣】伏睹聖制〔觀，當也；見也〕，文約而義深，法簡而用繁〔約，簡少也〕。
其連陣之外陣者，六七八九之數也；內陣者，五十之數也；間陣者，一二三四之數也。此法河圖之文也。
合陣之中衛包內外者，五十之包內外也；四衛之離子方者，一六二七三八四九之各離子其方也。此法洛書之變也〔離，附麗也。易大傳曰：河出圖，洛出書，聖人則之。天一生水，地二生火，天三生木，地四生金，天五生土，地六成之……〕。

== 05L–06R 河圖洛書之數與陣法 ==
河圖之一六為水，二七為火，三八為木，四九為金，五十為土，則自洪範之五行也。
河圖之數五十有五，洛書之數四十有五。
孔安國曰：河圖則八卦是也，洛書則九疇是也。
劉歆曰：河圖、洛書相為經緯，八卦、九章相為表裏。
劉歆曰：虙犧氏繼天而王，受河圖而畫之，八卦是也；禹治洪水，賜洛書而陳之，洪範是也。
洛書：禹治水，神龜負文而出，列於背，有數至於九，禹因而第之，以成九類。箕子陳之曰：天乃錫禹洪範九疇，初一曰五行……
河圖者，伏羲氏王天下，龍馬出河，遂則其文以畫八卦，是為先天之數。
（八卦與數相配：離、坤、巽、兌、艮、震……）

== 06L–07R 河圖洛書之數（續） ==
……朱子曰：天一而正，地二而偶，天三而奇，地四而偶……
朱子河圖洛書之說：河圖之位，一與六共宗而居乎北，二與七為朋而居乎南，三與八同道而居乎東，四與九為友而居乎西，五與十相守而居乎中。蓋其所以為數者，不過一陰一陽、一奇一偶，以兩其五行而已。
天一地二，天三地四，天五地六，天七地八，天九地十。天數五，地數五，五位相得而各有合。
以奇生者成數，以偶生者成數，此河圖之全數合積之奇偶也。
（按：此段大字正文与双行小注交错，注引《易大传》《洪范》孔安国、刘歆、朱子诸说以证阵法之数出于河洛。因注文密布，本稿摘录可辨读之正文与要注，余详原图。）

== 07L–08R 河圖洛書立陣（續） ==
〔朱子曰〕洛書之數，一與九為十，二與八為十，三與七為十，四與六為十，五與五為十。
凡數皆自一二三四五六七八九十而生。天一地二，天三地四，天五地六，天七地八，天九地十，而天地之數具矣。
易曰：河出圖，洛出書，聖人則之。又曰：參伍以變，錯綜其數，通其變，遂成天地之文；極其數，遂定天下之象。
朱子曰：河圖之數，一與六共宗而居乎北，二與七為朋而居乎南，三與八同道而居乎東，四與九為友而居乎西，五與十相守而居乎中。此河圖之數也。
洛書之數，戴九履一，左三右七，二四為肩，六八為足，五居其中。
陣之分也：內陣為五十之包內外，外陣為六七八九之各居其方，間陣為一二三四之各居其隅，合陣之中衛五也。
一衛之一分，一偏一奇，各以其數相為表裏，而以奇偶分陰陽、以生成別老少。
（按：此數頁皆大字正文與雙行小注交錯，注引《易大傳》及孔安國、劉歆、朱子諸家河洛之說以證陣數之所出；本稿摘錄可辨之正文與要注，餘詳原圖。）

== 08L 陣之體用方圓動靜 ==
圓聚方以守之，圓以行之，此法天地之（象也）。
體也：方而靜，外陣方而內陣圓；（用也：）方而動，內陣圓而外陣方。此陰陽之用也，各保於外，智藏於內。
分陰陽、別內外，此法之體用也。
陣有牝牡，夫婦之別也〔牡音某，牝音毗。唐太宗曰：李勣言牡牝〕。
（按：此段言陣有體用、方圓、動靜、內外、陰陽之別，並以小字注训释「牝牡」「聚」「行」等字，引唐太宗、李勣語為證。）

== 09R 八倫教兵（正文） ==
令不愆，朋友之信也；隊相依愛，兄弟之情也。此法八倫之道也。是故教兵而民知禮義，國家恒安。
（小字注引《左傳》晉文公事：民未知義，於是出定襄王以示之義；民未知信，於是伐原以示之信；民未知禮，於是大蒐以示之禮；三年欲用之。又引范蠡曰：凡陣之道……陣有牝牡，左右牝牡，早晚早晚……八陣之法，一守一戰。以奇正分陰陽，以早晚別牝牡。）

== 09L 太祖躬擐甲胄（正文） ==
太祖莫不躬擐甲胄，親駕四方〔擐，音患，貫也；甲，鎧也；胄，兜鍪也；駕，音加；馳，直也〕……
乃遠害於宴安耳〔傳曰：宴安酖毒，不可懷也〕。
國之大事，在祀與戎〔左傳：國之大事，在祀與戎〕。
（小字注：十二戰成湯，二十七征。湯，商王號，名履，姓子氏，以七十（一）戰而有天下；漢高祖姓劉名邦；唐太宗姓李名世民；漢祖、唐宗皆以征戰而成。軒轅（黃帝）……）
（按：正文之「太祖」指朝鲜太祖李成桂，以湯、漢高祖、唐太宗為比，是此書為朝鲜官撰之確證。）

== 10R 教戰（正文） ==
聖曰：不教民戰，是謂棄之〔言用不教之民以戰，必有敗亡之禍，是棄其民也〕。民不素習於平日，誰能禦侮於倉卒〔素，猶預也；倉卒，急遽貌〕？
故教戰者，國之大事也。夫孰不愛七尺之軀（身也），重百年之命？
首赴敵者，復殘也〔爭首，謂為先首，涉血爭為先〕。
諒由教之豫而法先定，勢先同而氣力成也〔諒，信也。管子曰：教士三萬，橫行於天下〕。
（小字注：管子，齊人，名夷吾，相桓公，霸諸侯。管子書言於桓公曰：公欲速得志於天下諸侯，則事有所隱，而政有所寓。）

== 10L 軍制（伍兩卒旅師軍） ==
……萬二千五百人為軍，故以軍統……以二千五百人為師，以五百人為旅，以百人為卒，以二十五人為兩，以五人為伍。（按：周禮司馬法之制，而配以朝鲜里、鄉、家之編戶以起兵。）

== 11R 兵之所由起（正文） ==
勝君有此教士三萬人，以橫行於天下，誅無道，以定周室，天下大國之君莫之能圉〔圉，此無化變，剛柔而同其勢耳〕。
一家大而天下無非勢合而成也，始也。乾坤之既判也〔判，分〕，善惡之必有對，治亂之必相因。愚迷之徒有貪心，有怒心，有爭心，有負心……
違負力者，則王者當有以接之也〔負，恃〕。
故不得已制為干戈，以討不服，兵之所由起也〔干，楯也，所以蔽身者；戈，戟也，長八尺有六寸，主於刺〕。
亂勢既制，（兵）也及乎釐清海晏，豺狼屏跡，揖讓之禮，斗斛威儀（示清也，言不波浪也）……

== 11L 制禮樂（正文） ==
放馬投戈，講藝息馬〔書：光武中興，投戈講藝，息馬論道〕。作樂時敘九功，乃歌七德，此因治勢而制禮樂。
（小字注：《左傳》：武有七德，我無一焉。武王克商，作頌曰：載戢干戈，載櫜弓矢，我求懿德，肆于時夏。又：夫武，禁暴、戢兵、保大、定功、安民、和眾、豐財者也，故使子孫無忘其章。九功：金、木、水、火、土、穀、正德、利用、厚生；九敘惟歌，言九功之敘可歌也。六府三事謂之九功，九功之德皆可歌也，謂之九歌。）
……名之曰秦王破陣樂，即（立）方（舞）也。唐太宗製樂……破陣樂（七德舞）……
（按：正文以唐太宗《破陣樂》當「七德舞」，與朝鲜朝廷行破陣樂之事相應。）

== 12R 兵之出入無非勢（正文） ==
……禁暴、戢兵、保大、定功、安民、和眾、豐財也。
然則兵之出入，無非勢也。臣觀歷代人士徒事浮華文彩〔凌，轢也；夷，平也；陵，侮也〕，治道陵夷者多矣〔夷，平也〕……
殿下先修軍政，保安吾民哉！
（小字注引輪扁斲輪事：桓公讀書於堂上，輪扁斲輪於堂下，釋椎鑿而上，問曰：君之所讀者，何言耶？公曰：聖人之言也。曰：聖人在乎？公曰：已死矣。曰：然則君之所讀者，古人之糟粕也。）

== 12L 序末（落款） ==
……（承前）王懇納民休和，何有〔逆，音刻；歷也；刻，刀切也；歷，遠也〕？（和兵不選，用致之於休和；息，諸禍亂已平也。）
**景泰二年辛未六月初三日，首陽大君【臣】諱奉教序。**
陣法序（終）

**落款考（本次新得，关键）**：
1. **「首陽大君」即後之朝鲜世祖李瑈**（1417–1468，世宗第二子；1453 年癸酉靖難奪權，1455 年即位為世祖）。此序作於其為首陽大君之時。
2. **「景泰二年辛未」＝1451 年**（景泰元年 1450；1451 正當辛未，即朝鲜文宗元年）。是此書之進呈在校定之年，與序首稱「余河崙、卞季良……撰集陣說」之舊本相承——河崙卒於 1416、卞季良卒於 1430，乃太宗、世宗朝之初纂，而此本為文宗元年重定之本。
3. 序末又列纂修官鄭麟趾、金孝誠、黃守身、趙由禮、金有銑、宋處儉、權擥、洪允成，於兵曹會議定之；權擥、洪允成皆世祖潛邸舊僚。
→ 合此三證，可定：**《陣法》為朝鲜官撰兵書，太宗、世宗朝初纂（河崙等），文宗元年（1451）重定進呈，序出首陽大君（世祖）之手**，江戶初期傳寫。此前著錄「著者文宗王」之題，當理解為文宗朝頒行之官撰本；而序之撰人則是首陽大君。

== 31L 陣法・分數第一（文） ==
右角题「陣法」。首目「分數第一」，旁系小注：「補註：分謂位部曲為數」（草書兩行，字序臆次）。

正文逐列可辨者（右起）：
一列：大將有五衛，每衛各有五部○
二列：每部各有四統〔統以下次列漫漶，惟「統」「旅」「隊」諸名迭見，似統領四旅、旅領四隊〕
三列：騎兵二統，一為戰〔騎〕，一為駐〔騎〕；步兵二統，一〔為戰步、一為駐步〕……人數雖不滿〔可闕？〕……
四列：〔……之名不可加？〕五人為伍，〔二？〕十〔五？〕人為隊……皆在〔中衛？〕……中部之兵多於各部

（按：此頁以五方色大麾為合陣之總機關：色召其衛，黃麾召中，與他色並點則四衛連中而成一大陣——「並點」之法，正是 26L–31R 五衛連圓陣圖之操作說明。交龍旗（大將旗畫龍文，見 33R）與標旗建偃之節，補 33R 「應交龍旗令」之用。）

== 38R 軍令第五（續）（文） ==
主線確線：

- 「失斥候煙烽更〔守？〕〔者？〕〔罪？〕」——斥候烽燧失職之罪

== 38L 軍令第五（續）：連坐之鏈・下營・君問（文） ==
主線確線：

- 亡失連坐之鏈（承 38R）：「斬其旅帥；己旅帥則斬其隊正；己隊正則斬其〔伍長？〕」「其位長；己位長則斬其卒」「左右近卒不救〔者？〕〔罪？〕」——亡將之罪逐級下逮，近而不救同科
- 恕免條：「若因不虞而將亡，則不在此例」（確）——不虞（出於不意）者免坐
- 「不利〔便？〕者罰，告有罪者賞」（確）——告訐有賞
- 下營之禁：「諸衛下營皆百分〔地？〕」「地明其界限」「非將令不通行」「菜薪芻牧〔無禁？者罰？〕」（注：「草也」「牧也」）——營界分明，樵牧有禁

- 「宣傳標信令〔於？〕將卒」注「諸將各傳令令部將」
- 「諸營幕作食，須及早〔晨？〕」「騎以後〔？〕」

（按：軍令第五至此兩翼俱備：上連坐而勵救，下立營禁而通行標信。「若因不虞而將亡則不在此例」一條最可注意——法有經權，非一於嚴。「君問曰、荅曰」之體，承 37L 軍令篇而啟下營諸問，是進講教本口吻；「下營」以下當即第五篇之營陣問答。）

== 39L 行軍次第・地形旗號・輜重輕騎（文） ==

== 41L 勇怯之勢・合戰操演（文） ==
主線確線：

- 「左右軍結陣相當」（確）注「以陣形相勝負〔？〕」——兩軍對壘較勝負
- 「各出戰銳及遊軍」「依法而進」「鼓〔噪？〕大呼」「合戰良久」（確）——對壘交戰操
- 金鼓退止：「〔金？〕則皆退二三步」「〔進？〕不過〔六？〕伐而止〔？〕」——進退以金鼓為度（「六伐」待複核）
- 「兵皆退，每退二十餘步，廻示賣勇之形〔？〕」（確線「兵皆退」「每退二十餘步」）——佯退誘敵之操
- 「示實勇之形」（確）——與「賣勇」對文：一虛一實，皆示敵之形
- 「後整列選營〔？〕」——操後整隊歸營
- 右緣注：「利則在後〔？〕」等（待複核）

（按：此頁演**勇怯之勢**——賣勇者佯北以誘敵，實勇者示強以懾敵，閱場之中兩形俱操，使士卒識詐與實之別。孫子「能而示之不能」之意，落為教閱科目。「左右軍結陣相當」承 40L，兩頁相銜，大閱戰操之全節可按。）

== 42R 勇怯之勢三（文） ==
篇記：「勇怯之勢三」（右緣確——勇怯之勢分一二三節，41L 當為其一）。

主線確線：

- 「二將敗退，則領將馳進救之」（確線「敗退」「領將馳進救之」）——前軍失利，領將赴援
- 「軍領將〔示？〕進，與其統將并力急擊」（確線「與其統將并力急擊」）——兩級合兵急擊
- 「旗而馳進」「示擊疾〔？〕」「若勝若敗」——勝敗兩形皆操
- 「若勝……領將束〔兵？〕勝逐之，到敵營〔？〕還」「皆遊軍殺後〔殿？〕」——勝則逐敵至營，遊軍為殿

- 「銳十餘步，立〔？〕示賣勇之形〔？〕」

（按：勇怯之勢三節，一演實勇（41L），此節演**敗而復振、勝不窮追、追而設伏**之全套：敗退有領將赴救，合兵急擊，勝則逐至敵營而遊軍殿後，隨即回旗再演賣勇——閱場如臨陣，教至於變而無窮。佯退「二十餘步」之數與金鼓止擊之節相配，操典之細如此。）

== 42L 主客陣演戰（文） ==
主線確線：

- 「主陣堅守不動」（確）——主陣之應：壁而勿動
- 「前統及遊軍向〔？〕」「依法〔五？〕左〔右？〕步許，擊〔三？〕止〔？〕候衛〔？〕」——出擊以步數為限，擊而復止（行次待複核）
- 「客陣少出遊軍尾擊之，得戰而退」（確線「少出遊軍」「尾擊之」）——客以遊軍繞後挑戰

- 「三衛各戰角三通」「青白赤三角〔？〕」「將以指標旗〔？〕」——三通戰角、色角分衛
- 注：「以戰報大將」「賊誤踊報〔？〕」——戰況報聞大將

（按：此為大閱之**主客對演**：客逼而主守，各以遊軍尾擊為試，戰不出步數之外——教場如敵場，而分寸皆在法度。三通戰角、色角分衛，與 41R 節次相銜。主客之名承 35R 合陣主客之義。）

== 43R 主客演戰・奇兵・神機箭（文） ==
主線確線：

- 「客兵又來，則遊軍〔抄？〕入〔？〕」（確線「客兵又來」「遊軍」）——遊軍為應援之兵
- 「客兵又不得戰而退」（確）——客再挫
- 「主陣……出奇〔兵？〕」「〔張？〕左右翼，掩後擊之」「又出戰銳，大呼夾〔擊？〕」（確）——主陣出奇：兩翼掩後、戰銳夾擊
- 「客兵〔頻？濱？〕出三，不得戰而還於陣〔？〕」——三出三挫
- 「放神機箭，以應吹戰角」（確線「神機箭」）——**火器入教閱**：戰角起而放神機箭
- 「其遊搖旗，以戰鼓誤(噪？)大呼」「指戰角，立標，部將以戰鼓擊之」
- 注：「大將指青〔龍？〕翼白疾趨掩右後〔？〕」

（按：演武至此愈奇：客三出而三挫，主乃出奇——張翼掩後、戰銳夾呼，末以**神機箭**應角而發。神機箭者，朝鮮火矢也，崔茂宣以來國家習之，世宗朝火砲火箭列于軍制；此書以之入教閱儀注，且施於王前（40L 駕前放砲），是文宗朝教場之實況。兵法「以正合，以奇勝」，此頁足為之圖解。）

== 43L 勝敗之形一（文） ==
前半承演武：

- 「主軍逐之，繞營示勇〔而選？〕」——主勝之後繞客營示威
- 「主軍兩翼及三衛，銳繞客營，左右潰散〔敵？〕選營〔？〕」「揚威示勇」——兩翼銳騎繞營揚威
- 「應而旗麾擊，止金，又吹大角〔？〕」

新節：「勝敗之形一」（大字確——與「勇怯之勢」同為分節之體）

- 「左右軍結陣相當，依法出兵」（確）
- 「合戰良久，主兵佯敗而退」（確）——**主佯敗**：與 42R 客挫主振相對成局
- 「客兵領將統將，乘勝逐利，進迫主營」（確）——客乘勝窮追
- 「力逐擊〔？〕」「主陣敗〔選退？〕戰統與駐統并〔力？〕」

（按：勝敗之形與勇怯之勢為對篇：勇怯演士氣之真偽，勝敗演**局勢之逆順**。前節客佯敗而主出奇，此節主佯敗而客窮追——兩軍互易，敗者之救、勝者之戒，皆在教場中操練。佯敵者習誘，窮追者防伏，先後相成。）

== 44R 勝敗之形（續）：主陣全反攻（文） ==
主線確線：

- 「其後客軍逐利之半，敗潰〔？〕」（確線「客軍逐利」「敗潰」）——客深入而半潰
- 「選主陣左右前三衛將，各吹戰角，以戰鼓擊之〔？〕」——主陣三衛應角出兵
- 「五衛皆出戰統」「領將因為先鋒，來襲衝客陣」（確）——**五衛總攻**：領將為鋒
- 「陣而大將以下，盡率守營之兵，繼從而行」（確）——大將親率營兵繼進
- 「客陣左右前衛先遯，中後衛亦不能支」（確）——客陣瓦解之序
- 「銳將各點標旗以應之」（注）

（按：主客演戰至此翻入**全師總攻**：先鋒（領將）衝陣，大將率守營兵繼進，五衛戰統盡出——「守營之兵」云云，見營與陣各有其兵，戰守互為表裏。客陣「左右前衛先遯，中後衛不能支」云云，並寫潰軍之序，教場中並習敗狀，使將士識敗象而制變。）

== 44L 營敗走（文，密注夾書，待複核） ==
篇記：「營敗走」（右上大字確）。本頁主注交錯最密，可辨者：

- 「主〔陣？〕鼓營」「陣戰守〔之法？〕」——戰守互用
- 「大將〔吹？〕大角」「三營〔？〕將立吹兵」「營戰部衛而箭」——角令總攻續
- 「守營之兵五〔衛？〕應之」「以戰〔統？〕」
- 「先〔鋒？〕遊〔軍？〕將」「雲〔蒸？〕下〔？〕角麾」「以鳥擊〔？〕以及〔？〕」——奇襲諸式
- 「神機〔箭？〕應衛」「指銳〔旗？〕」「衝〔？〕客〔陣？〕領〔將？〕統旗〔？〕」「勢〔？〕」
- 「散戰遊下舉軍〔？〕」

（按：營敗走者，追奔逐北至敵營之節歟？就所辨「大角」「守營之兵」「遊軍先」「神機箭」「衝客陣」諸語觀之，當為總攻之餘波——大軍銜尾而進，守營之兵繼發，神機箭張勢，直薄客營。行次未遑釐定，併 31L 左半、32R 俟終校專頁重讀。）
