== 0004/0005 書名葉＋序（起） ==
書名葉大字：「玉京山人著　易鈔五種　楊卓訂」。左下鈐朱印「哈佛大學漢和圖書館珍藏印」。右上一舊簽條倒貼，反字可辨：「世有表章此書者（?）急宜刊去識者自能辨之　老初（?）徐棟謹志（?）」。
序（起）：「道無言也，聖人不得已而有言，非聖人之言也，天地之言也。道無象也，聖人不得已而有象，非聖人之象也，天地之象也。凡出自聖人之手而適（?）如其自不假思索，而莫知其所以然者，蓋莫非天地之借（?）徒現於龍之身、龜之背，聖人從而則之者也。大真先生遊心象外，思入元微，其所造之（?）……」

== 0006 序（承） ==
「……所得而窺測者，獨其所著大真一得。蓋出自創見，獨抒心解，以發古聖之精，以洩天地之秘。豈非宇宙間一快事哉。第閱之者未數（?）思臥，益以庸俗之目對微妙之理，宜其格格；如而粗通大意，亦未嘗無管窺之一二。而以卓之頑鈍不敏，乃能詳閱數周，雖其精微幽（?）……先生亦許為知已而樂與講論不置也。〔自）抒於乾隆之丁卯，成於乾隆之癸酉，前後六七年間，或數年而無一字，或傾刻而數百言，汨汨滔滔不加點竄，自爾成理；暢有苦心焦思而不能得者，忽然得之一旦，在（?）先生亦不解其何處收蔵如許也。然則大真一得一書（?）亦天地欲洩此理於今日，而特假手於先生而出之，豈（?）先生之言、先生之象子（?）……」
（按：序自述「抒於乾隆丁卯、成於乾隆癸酉」——乾隆丁卯 1747、癸酉 1753，前後六年餘；「卓」自稱即楊卓（臥雲子）。）

== 0009 目終楊卓再識＋造化太極圖說（起） ==
「目终。右书十馀卷，阐惟八宫图说上成帙（?），又天图说先天图说观音说又次，造化太极图说馀俱成（?）。而今之序如右，盖以理为次而不计其岁月之先后也。化太极图虽非出于古圣之手，而太极之所有是形者，于此始见其图之出于自然而得其所以然，故以列说篇首。观音说则因俗谈而阐推之，虽亦未始非妙理，而意杂羌（?）氏，益亦游衍之戏笔耳，故以附诸篇末云。杨卓再识。」
正文起：「造化太极图说　玉京山人于濬英著」
「子曰动静无端阴阳无始。曰剥之为卦也，诸阳消剥已尽，独上九一爻尚存，然阳无可尽之理，尽于上则生于下，无间可容止息也。阴亦然，圣人不言耳。窃以此两言泄尽造化之机矣，因图以明之，而又为之说，以俟夫知道之君子赐针砭焉。乾隆癸酉年春二月题。
太极者道也，形而上者也。形而上不可以象（?）……象之者借器以象之而已（?）」（承 0010）

== 0010 造化太極圖說（二） ==
「亥為陰之極，陽之盡也；巳為陽之極，陰之盡（?）……盡于此則生（?）于此。畫之時即生之時也。造化之機，其來有漸，不遽有也；其去有漸，無不遽無也。復之一陽一陰之成也，姤之一陰一陽之成也，然非思無而成也。故陽始于小雪，陰始于小滿。剝之一陽之存也，夬之一陰之存也。至於坤猶有未盡，蓋剝之陽故必至小雪而後為剝之盡；至於乾猶有未盡，盡剝之陽故必至小滿而後為夬之盡。
陽去為剝，不必戌也；陽來為復，不必子也；陰去為夬，不必辰也；陰來為姤，不必午也。然則何以為乾坤？曰動靜無端，陰陽無始者，理之于一也；復姤各擅其盛者，分之殊也。是故泥分之殊而忘理之一者，非也；執理之一而疑分之殊者，亦非也。觀復之一陽生于小雪，則臨之二陽生于冬至也，子知（知子?）矣。則泰之三陽生于大寒（?），大壯之四陽生于雨水，夬之五陽（?），乾之六陽生于穀雨也可知矣。」
旁注：「陰陽之始於春秋……云始於巳亥，非聖人……」
（按：以十二月卦（十二辟卦）配節氣言陰陽消長——復一陽小雪、臨二陽冬至、泰三陽、大壯四陽雨水、夬五陽、乾六陽穀雨；陽盡於亥、陰盡於巳之數術化以太極。）

== 0011 造化太極圖說（三） ==
「道不離器，亦不滯於器中也；滯者自滯也。往古來今千萬載，一太極也；上下四方呼吸間，一極也。然遠而不可見也，微而不易察也，可得而易見者，其一歲乎！一歲之中寒暑迭禪，太極之象也。然寒於何日，其界不可指也；暑於何時，其節不可畫也。氣不可畫，其節也；而理可指，其界也。
先儒於六十四卦中取復、臨、泰、大壯、夬、乾，始遯、否、觀、剝、坤十二卦，以象一歲陰陽消長之機，未嘗以此明太極也。間嘗竊取見焉。（邵?）子之意合而圓之，而所謂一歲有太極之理者，思（息?）焉。
人知陽之始於春也，而不知陽之始于子也；人知陰之始于秋也，而不知陰之始于午也……」
旁注：「陰陽之始於春秋……云始於巳亥，雅非聖人……乾隆知之」

== 0012 造化太極圖說（四） ==
「觀姤之一陰生于小滿，則遯之二陰生……可知矣。則否之三陰生于霜降……坤之六陰……陽極于巳，而一歲之大暑乃在未申，陰所逼也，逼盡陽于地上，故其暑愈猛，至于酉陰始出地而暑退矣。陰極于亥，而一歲之大寒乃在丑寅，為陽所逼也，逼盡陰于地上，故其寒愈烈，至于卯陽始出地而寒退矣。
豈惟一歲，一月之中有太極焉，朝望晦弦一陰陽四時也；一日之中有太極焉，晝夜朝夕一陰陽四時也。一歲而外，安知數十年中無一陰一陽乎？安知數百年中無一陰一陽乎？安知數千年中無一陰一陽乎？安知數萬年中無一陰一陽乎！
豈惟天地，人身之中有太極焉，少壯衰老一陰陽也，窮達通塞一陰陽也，憂樂相尋一陰陽也。豈惟一身，一家之中有太極焉，盛衰興敗一陰陽也，治亂存亡一陰陽也。豈惟一家，一國之中有太極焉……」
（按：太極遍在論——由一歲而月、而日、而數萬年，由天地而身、而家、而國，層層推衍。）

== 0013 造化太極圖說（五） ==
「祗此一氣，近在一息呼吸，遠在天地終始，今與道為體者，命之所以流行而不已也。一氣二分之為四時，四分之為十二月，十二分之為二十四氣，二十四分之為七十二候，七十二分之為三百六十日，脈絡分明，井井不亂者，分之所以一定而不易也。
剝者落也，惟恐其落，故於其將落也名之曰剝，蓋惜之也。復者返也，惟恐其返，故於其方返也名之曰復，蓋喜之也。古聖人之扶陽也如此。
夬者決也，急欲其去，故於其將去也名之曰夬，決之使去也，快之也。姤者遇也，惟恐其來，故於其方來也名之曰姤，蓋曰又遇其來也，憂之也。古聖人之抑陰也如此。
剝而必復，復而必剝，夬而必姤，姤而必夬……者，數也，命也，天道也，人之所無如（?）何者也，聖人於此罕言焉。剝而惜，復而喜，夬而快，姤而憂者，理也，性也，人之所當自盡者也，君子於此乾乾焉。」
（按：卦名訓釋寄扶陽抑陰之情——「天道罕言而君子自盡」，理一分殊之旨。）

== 0014 造化太極圖說（末） ==
「古之君子其治國也，安不忘危，其治家也（?），忘食其治身也。是故几杖盤盂皆有銘焉，動容周旋必以禮焉，所以養善於未形、絕惡於未萌也。望道未見，曾子南容之所以賢也。書曰吉人為善，惟日不足；凶人為不善，亦惟日不足。召烈（?）曰勿以善小而不為，勿以惡小而為之。子思曰莫見乎隱，莫顯乎微，故君子慎其獨也。又曰戒慎乎其所不睹，恐懼乎其所不聞，君子之道盡于此矣。詩云維天之命，於穆不已，蓋曰天之所以為天也；於乎不顯，文王之德之純，蓋曰文王之所以為文也，純亦不已。聖人之道盡于此矣。」
（按：卷一造化太極圖說以慎德收束——由天道之不已轉出君子慎獨之修，中庸結穴。）

== 0018 太極八卦一體圖說（起）＋題詩 ==
題詩（九句）：「鬼聖揭（撼?）其委　後聖探其端　千年有大真　鑒破渾淪團　淵微縱橫出　能分復能連　機竅透劫前　昊天洩妙理　又假玉京山」。
說文：「太極八卦一體圖　玉京山人于濬英著。太極者陰陽消長之機也，理至此無以復加矣，以其無理之可名，故強名曰太極。孔子曰易有太極，是生兩儀，兩儀生四象，四象生八卦。道之至極，先聖每不欲盡言之，〔孔子〕是說是有太極而又有兩儀，又有四象，又有八卦，豈有是理哉！止此一○，分之為〔陰陽兩半圓〕則為兩儀，又分之為〔四分圓〕則為四象，又分之為〔八輻圓〕則為八卦，推之六十四卦，其○一也。」

== 0019 太極八卦一體圖說（二） ==
「是八即四也，四即兩也，兩即一也。然則孔子之言非乎？曰孔子之說不得已而舉其似，形而下之言也；吾之說不能思而露其真，形而上之言也。一元之氣陽長陰消、陰長陽消，古人強為〔太極圖〕以明之，又列之以八卦，可謂竭揭其密以示人矣。不如是，人不知八卦為太極；然如是，則人又泥太極之外有八卦，甚定理之難明也。太極八卦之渾淪，統一之道也；分殊之道也。
以〔太極圖〕分之：正北純陰之象也，東北陽初升陰盛之象也，正東純陽冒之象也，西南陰初升陽猶盛之象也，正南純陽之象也，西北陰長陽消之象也。
八卦之各為其體也。四分之則南皆為乾、北皆為坤、東皆為離、西皆為坎；又四分之則東北皆為震、東南皆為兌、西南皆為巽、西北皆為艮。八卦之互為其體也。」
（按：「八即四、四即兩、兩即一」統一分殊之辨；太極圖黑白配置配先天卦象（正北純陰坤、東北陽初升震、正東純陽離、東南陽猶盛兌、正南純陽乾、西南陰初升巽、正西陰盛坎、西北陰長陽消艮）。）

== 0020 太極八卦一體圖說（三） ==
「論四象則南為太陽、北為太陰、東為少陽、西為少陰。以〔四分圖〕論兩儀則南為陽而北為陰。以〔八輻圖〕論兩儀則東南為陽而西北為陰。以〔太極魚圖〕論兩儀則……東南為陽而西北為陰。此又兩儀之互為其體也。乾一兌二離三震四巽五坎六艮七坤八，此八卦自然相次之第也。
乾兌離震為陽之卦，而太極之位則到於東南；巽坎艮坤屬陰之卦也，而太極之位則到於西。陽以壯為貴，故先盛而後微；陰以少為美，故先微而後盛。陽自南而東自南而西而北，上北下也。以上下觀陰陽並立之象也。
陽似逆陰似順，陰陽顛倒交互之象也。陽以動為本，靜則逆而動則順也；陰以靜為本，靜則順而動則逆也。然其逆也以隨乎陽而動也，動隨乎陽，其逆乃其所逆也……」

== 0021 太極八卦一體圖說（四） ==
「〔八卦〕以順也。八卦八方方其外者中含一，一者九也，八之所拱也。乾一與坤八合一與八合九也；東北震四與西南巽五，四與五合九也；東南兌二與西北艮七，二與七合九也（〔洛書對待合九之義〕）……卦三畫，八卦共二十四畫（陽十二陰十二），然陽□一而陰□二，再加之得三十六，此三十六之散見者也。
上天地萬象森然羅列古今，不貴安排。四時行焉，百物生焉，上天何言哉！予何言哉！孔子曰予欲無言。夫無言之為妙，生天地乃是真竅。自然之道無為之妙，天地合其德，日月合其明，風雷合其變，山澤合其潤。聖人因萬物之宜，順萬物之能，各得其所，乎天成無為而治天下太平。唐虞而後惟孔子乎！無意無必無固無我，渾然一理泛應曲當，老者安之朋友信之少者懷之，因物付物己不與焉，故其……」
（按：洛書對待合九、二十四畫加至三十六之數理；引論語予欲無言、無意無必無固無我以贊無為之易。）

== 0022 太極八卦一體圖說（末）＋後天八卦方位圖 ==
「告景公曰君君臣臣父父子子。嗚乎至矣，蔑以加矣。君子不以私喜，公不以私怒（?）。敬以承天，義精仁熟，萬復本原。太極在我身，具先天八面玲瓏，曉月落萬川。」
（圖）題「後天八卦方位圖」——離上坎下、震東兌西、巽東南、坤西南、乾西北、艮東北。圖下說：「乾坤離坎先天之正方也；震兌巽艮先天之隅方也。正方居正方者乾坤是也；隅方居正方者震兌是也；正方仍居正方者離坎是也；隅方仍居隅方者巽艮是也。」

== 0023 乾坤六子之圖＋後天八卦圖說（起） ==
（圖）題「乾坤六子之圖」——乾父☰坤母☷居上，震長男坎中男艮少男、巽長女離中女兌少女列下。
圖下引《序卦》：「有天地然後有萬物，有萬物然後有男女，有男女然後有夫婦，有夫婦然後有父子，有父子然後有君臣，有君臣然後有上下，有上下然後禮義有所錯。」
正文：「後天八卦圖說　玉京山人于濬英著。
萬物未生，生於天地；萬物既生，生於萬物（?）。既在男女而在父母，無事矣。男女未生，道在父母；男女既生，道在男女，而父母無事矣。天地之形東陽而西陰，陰陽之理陽外而陰內（?）。內之勢外進而內退。父母無事，怡老居休，故退處於無為之鄉。」
（按：卷三後天說以父母生子喻乾坤生六子、道之遞嬗退休。）

== 0024 後天八卦圖說（二） ==
「以天地陰陽之理觀之，戌亥之間陰之極而陽之絕也，陽絕無所用其陽，故乾之老也，居之純乎無為也。未申之間陽之極而陰之絕也，陰絕無所用其陰，故坤之老也。然未申之氣雖陽而已陰（?）……蓋陽尊而陰卑，坤之體雖無為而心則未嘗無為（?），猶之父母同老而父母未（?）能全逸也。天老陽而地老陰，火少陽而水少陰。老陽退而少陽代，少陰退而少陽（陰?）代。離之所以居乾位也，坎之所以居坤位也。
離女也亦少陰也，老陰之變必少陰，故乾之後為離。坎男也亦少陽也，老陽之變必少陽，故坤之後為坎。坎中男也，長男經營四方，常居于外，不可主家政，故主家政者以中男（?）。離中女也，長女已適人，不可與家事，故與家事者以中女。震之正東，離父母最遠，長男居外之象也；巽之東南，離父母亦遠，長女適人之象也。」

== 0025 後天八卦圖說（三） ==
「艮隨長男於外，十年出就外傅之象也；兌依父母而居于內，女子十年不出之象也。離坎之主政非離坎之定位也。有乾坤則坎離為男；如無乾坤則坎離為父母矣。坎離為男女則主事；坎離為父母則坎亦將退休矣。坎離退休則又有坎離之男女主事矣，此生生不息繼續無窮，世運嬗代之常道也。而長男長女之為父母，坎于此可推矣；而少男之為長男、少女之為中女（?）如為長女為母，又可推矣。
陽絕西北亦生西北，酉者陽之原也，乾之居此，反本還原之理也。陰本絕東南而生於東南，再生于西南者，陰再生之源也，坤之居此亦反本還原之理也。坤之原必再著母以道人（?）……二而後嫁，非始生時也……申土之（?）並坤也，配合而成之象也，今已歸原矣。」
（按：後天卦位配人倫長幼家政之喻——出就外傅、女子十年不出用《禮記·內則》成語；生生不息世運嬗代收束。）

== 0026 後天八卦圖說（四） ==
「莫高于山，山之上天而已，故先為山而後為天。大地之始由風吹而堅（墾?），故先為風而後為地。火為氣之先，附木而後行于天；水為氣之質，先生（金?）而後行于地。雷火之聲也，雷之發也必先電，故先火而後雷。澤水之聚也，故先水而後澤。澤為水草之叢，風之所起也，故先澤而後風。雷于空近之者為山，故先雷而後山。
先天之天地，理也；後天之天地，象也。先天之水火，水火之氣也；後天之水火，水火之質也。先天之雷，無形之風雷也；後天之山澤，有形之山澤也。……乾坤讓離坎而退居艮巽之位，艮巽依方而同避于坎離之里。則艮巽有相向之理。先天之巽從天之坤也，則坤與艮有相連之勢；先天之艮後天之乾也，則乾與艮有相連之勢。巽艮居震兌之位，則震兌不得不移；離坎之位，則震兌又有相向之理焉。合觀之，縱橫成行（田形），九宮之象也。」

== 0027 後天八卦圖說（五） ==
「先天無為，天道也；後天有為，人道也。無為之道體也，有為之道用也。先天天地水火雷山澤，一定不移對待之理也；後天乾坤坎離艮巽震兌，變動不居流行之理也。先天之形四方相向，其象方而大；後天之形南北相向，其象順而簡。先天即理而道，其常，天地之常經也；後天即事而道，其變，古今之通義也。
乾坤離坎先天南北東西相向，此理勢之已相連者也。乾坤讓離坎而退居艮巽之位，艮巽依方而同避于坎離之裡，則艮巽有相向之理……合觀之縱橫成行，九宮之象也，縱橫皆申之象（?）。」
（按：先天後天之辨——理象、氣質、無為有為、體用、常變五對偶，為後天說之綱；「九宮縱橫」承前八卦九宮圖。）

== 0028 後天八卦圖說（末·後序） ==
「男女各有其分，長幼各有其職，老者尊者慈，而身無不脩矣，而家無不齊矣，推之而國治矣，天下平矣。勢位不可久居，功名不可久戀，知足不辱，知止不殆。孔子曰及其老也，戒之在得。養尊處優，每享期頤之樂；怡神休氣，償還少壯之勞。蓋觀于乾坤而知之。恭承先志，祖宗之法度不可更；敬慎貽謀，子孫之驕淫不可啟。蓋觀于離坎而知之。未衰不預（?），當身不辭，已過不貪，天下事興亡共為之，公莫公于此矣。問臻此（?）君子曰：有克己而已矣。未衰不預，姑求其志；當身不辭，竭力盡職；已過不貪，遂志樂天。人也，理也，勢也，一也。一者何也？曰仁也。克己行仁，由勉而安，渣滓消融，庶幾自然。身居後，天心是先天。曆筭（?）先生曰若問先天一事無，後天還得著工夫。蓋而已。心知其意而特隱而不發，不欲輕泄，以俟後人之參悟而自得也夫。出震齊巽之說，既不易解，而先儒之言道者……」

== 0029 後天八卦圖說跋 ==
「又未見其詳於（?）……也。予何人斯而敢云簽（筮?）先儒之所述，陰擄臂取于至道之途（?）。嘗竊取其說而推之，但覺寵（?）無一之妙趣，若管窺于萬意……立象之盡意，恍若管窺于萬性……吾向之疑而久（?）……吾向之疑耽（?）而一旦偶（?）然假手于吾（?），與闡發，遂能使……而聖人之意否耶（?）……說為燕說也，吾之罪大矣。願傳之（?）明貴造之儒賜之鍼砭，正其舛訛，不至上誣先聖，下誤後學，人也則幸甚。
乾隆十六年歲次辛未秋七月上浣吉日　瀛陽後學于溱（濬?）英文明氏敬跋」
（按：**跋落款乾隆十六年辛未 1751 秋七月**，自署「瀛陽後學于溱（濬?）英文明氏」——作者籍里瀛陽（直隸河間府一帶），名濬（溱?）英、字（號）文明，與卷端「于濬英甫著」合；跋自謙成書恐燕說誣聖，請儒者鍼砭。先後天圖說至此完，紀年得四：辛未制圖、辛未跋、癸酉題說、甲戌序。）

== 0032 八宮八卦次第說上（起）＋先天方位表 ==
（圖表）正南乾為天、正東離為火、西南巽為風、西北艮為山；正北坤為地、正西坎為水、東北震為雷、東南兌為澤——先天八卦方位表。
正文：「八宮八卦次第說上　玉京山人于濬英著。易者爻易之義也。伏羲既作八卦，復從八卦陰陽互相交易而得六十四卦。天與地相對也，故天與地互，地亦與天互；火與水相對也，故火與水互，水亦與火互；風與雷相對也，故風與雷互，雷亦與風互；山與澤相對也，故山與澤互，澤亦與山互。此相對者有相為交易者也。」

== 0033 八宮八卦次第說上（二） ==
「此四正相對與四隅相對為交易者也。以天地相對者逆于火水而歸于天地；以火水相對者逆于天地而歸于火水；以風雷相對者逆于山澤而歸于風雷；以山澤相對者逆于風雷而歸于山澤。
天地火水居四正者也，風雷山澤居四隅者也。以天地火水為經，則以風雷山澤為緯；以風雷山澤為經，則以天地火水為緯。
天陽而地陰，火陽而水陰，天與火皆陽類也，地與水皆陰類也。風陽而雷陰（?）……地水雷澤皆陰類，故緯地者以雷澤……以澤雷緯雷者……天遊于火，火亦遊于天；風遊于山，山亦遊于風……陰與陰從其類也，陽與陽各從……」
（按：交易說——四正四隅相對、經緯互緯、陽類陰類相從，釋六十四卦之所由生。）

== 0034 八宮八卦次第說上（三） ==
「其類也。地遊于水亦遊于地，雷遊于澤亦遊于雷，亦陰與陰各從其類也。天與風陽之純者也，純與純相合，故天先與風交而後及于山；火與山陽之次者也，次與次相得，故火先與山交而後及于風，山亦先與火交而後及于天。地與雷陰之純者也，純與純相合，故地先與雷交而後及于澤；雷亦先與地交而後及于水。澤與水陰之次者也，次與次相契，故水先與澤交而後及于雷。
陽無陰不成，故天火風山必以地水澤相互而成八卦，陽中包陰也；陰無陽不生，故地水雷澤必以天火風山相互而成八卦，陰中包陽也。天火相遊，地水相遊，正方仍遊正方也。」

== 0035 八宮八卦次第說上（末）＋于濬英自識 ==
「風山相遊，雷澤相遊，隅方仍遊隅方也。余于八宮六十四卦見其參差錯亂配合不倫（?），又見卜易者有遊魂歸魂之說而不能解。因思是必有其理。於是將乾卦一宮錯綜處畧加位置，忽成一圖。及徧閱八宮皆如此。遂將八宮各作一圖，列其次第。近復玩之，不得其蘊。乃知聖人所作，真有如天地設，確乎其不可易者，而遊魂歸魂之義亦遂不言而出矣。第八宮本以天地火水與風雷山澤互而成卦，則其次第固自有一定。不知後賢何故以乾兌離震巽坎艮坤為次，或又以乾坎艮震巽離坤兌為次，使聖人畫卦次第之妙湮沒而不彰。夫後天之學與先天各自為說，即先天八卦方位之序亦第就其來往順逆而言耳。今奮為此圖與說，不敢曰闡千古之秘，第欲自明其鐵（砥?）云耳。
乾隆十二年歲在丁卯夏五月　濡陽後學于濬英文明謹識于思誠堂」
（按：**圖成紀年乾隆丁卯 1747**——八宮圖實為全書最早之稿（序稱丁卯成癸酉者合）；籍里自署「濡陽」（0029 跋「瀛陽」異文待考）；斥後儒乾兌離震、乾坎艮震兩種卦次亂聖人畫卦之序，八宮本宮次第乃「確乎不可易」，並釋卜易遊魂歸魂之義。）

== 0046 八宮八卦次第說下（起） ==
（卷首鈐朱印一方，篆文難辨。）「八宮八卦次第說下　玉京山人于濬英著。
乾宮。天變第一爻則為風（姤），二爻變則為山（遯），三爻變則為地（否）……而乾之變盡矣。天一變而為風，故天與風交；風為天之一變，故次與山交；山為天之再變，故次與地交；乾坤之交畢矣。天之與風交，非與風交也，風變天之爻也，天與之交，是以天之爻與之交也……」（釋八宮一爻至五爻變及本宮上交之理。）

== 0047 八宮八卦次第說下（二） ==
「……姤者乾坤之交一爻也；遯者乾坤之交二爻也；否者乾坤之交三爻也；觀者乾坤之交四爻也；剝者乾坤之交五爻也。剝而乾坤之變盡矣。天包地而交，既交則天中虛而（氣）遊于外矣，天中一虛火之象也，故火又與地交，非火與地交也，以既虛之天與地交也……交地既畢而天退身去，不遠（?）……此一交亦非真交也……」（釋遊魂歸魂爻——火遊魂、天（?）歸魂之義。）

== 0048 八宮八卦次第說下（三·乾宮末坤宮） ==
「天遊漸遠于地，則天竟漸復其初，以既虛之天神返其宅，又火與天交之象也，故火天之大有為乾之歸魂。
坤宮。地變第一爻則為雷（復），二爻變則為澤（臨），三爻皆變則天地（泰），坤之變盡矣。地一變而為雷，故先與雷交；再變而為澤，故次與澤交；三變而為天，故與天交……再變故澤又與天交，而坤乾之交畢矣。地之與雷交非與雷交也，雷變地之一爻，此一爻實天之（?）……之二爻也……」

== 0049 八宮八卦次第說下（四·坤宮末離宮起） ==
「地天交泰，乾坤之交得其中者也。天地雷之復、地澤之臨，則坤有餘而乾不足，交之未及者也；及雷天之大壯、澤天之夬，則坤不足而乾有餘，交之已過者也。復也者坤乾之交一爻也，臨也者二爻也，泰也者三爻也，大壯也者四爻也，夬也者五爻也。夬而坤之變盡矣。
一虛水之象也，故水又與天交，非水與天交也，以既虛之地與天交也。水天之需為坤之遊魂；地遊漸遠于天，則地竟漸復其初，以既虛之地神返其宅，又水與地交之象也，故水地之比為坤之歸魂。
離宮。火變第一爻則為山（賁），二爻變則為風（鼎），三爻皆變則為水（未濟），而離之變盡矣。」
（按：坤宮復臨泰大壯夬五世＋需遊魂＋比歸魂，京房坤宮全合；「神返其宅」釋歸魂，語妙。）

== 0050 八宮八卦次第說下（五·離宮） ==
「火一變而為山（賁），故先與山交；再變而為風（鼎），故次與風交；三變而為水（未濟），故次與水交，而離之變畢矣。火之與山交非與山交也，山變火之一爻……火之與風交非與風交也，風變火之二爻……
火水未濟，離坎之交得其中者也。火山之旅、火風之鼎，則離有餘而坎不足，交之未及者也……蒙也者離坎之交四爻也，渙也者五爻也，未濟也者離之變盡矣。」

== 0051 八宮八卦次第說下（六·離宮末坎宮起） ==
「交五爻也。火包水而交既交，則火中虛而（氣）遊於外矣，火中一虛水之象也，故天又與水交，非天與水交也，以既虛之火與水交也，此一交亦非真交也。水既畢而火退，其去不遠，猶未甚離於水耳，故天水之訟為離之遊魂；火遊漸遠於水，則火竟漸復其初，以既虛之火神返其宅，又天與火交之象也，故天火同人為離之歸魂。
坎宮。水變第一爻則為澤（節），二爻變則為雷（屯），三爻皆變則為火（既濟），而坎之變畢矣。水之與澤交非與澤交也，澤變水之一爻，此一爻者實火之一爻（?）；水之與雷交非與雷交也，雷變水之二爻……水之與火交是以水之（一?）爻與火交也……」
（按：離宮賁鼎未濟蒙渙五世＋訟遊魂＋同人歸魂，京房離宮全合；坎宮起。）

== 0052 八宮八卦次第說下（七·坎宮末） ==
「交五爻也……水火既濟，坎離之交得其中者也。水澤之節、水雷之屯，則坎有餘而離不足，交之未及者也；澤火之革、雷火之豐，則坎不足而離有餘，交之已過者也。節也者坎離之交一爻也，屯也者二爻也，既濟也者三爻也，革也者四爻也，豐也者五爻也，豐而坎之變盡矣。水包火而交既交，則水中虛而（氣）遊於外矣，水中一虛地之象也，故地又與火交，非地與火交也，以既虛之水與火交也，此一交亦非真交也。水既畢而坎退，其去不遠，猶未甚離於火耳，故地火之明夷為坎之遊魂；水（火?）遊漸遠於火則漸復其初，以既虛之水神返其宅，又地與水交之象也，故水地之師為坎之歸魂也。」

== 0053 八宮八卦次第說下（八·巽宮） ==
「天與水交之象也，故地水之師為坎之歸魂。
巽宮。風變第一爻則為天（小畜），二爻變則為火（家人），三爻皆變則為雷（益），而巽之變盡矣。風之與天交非與天交也，天變風之一爻；風之與火交非與火交也，火變風之二爻；風之與雷交是以風之一爻與雷交也……天與風交是以風之二爻（?）與天交也……風雷益，巽震之交得其中者也。風天之小畜、風火之家人，則巽有餘而（震不足）……」
（按：坎宮既濟革豐五世＋明夷遊魂＋師歸魂，京房坎宮全合；巽宮小畜家人益三世起。）

== 0054 八宮八卦次第說下（九·巽宮末震宮起） ==
「而震不足，交之未及者也。天雷無妄、火雷噬嗑，則巽不足而震有餘，交之已過者也。小畜也者巽震之交一爻也，家人也者二爻也，益也者三爻也，無妄也者四爻也，噬嗑也者五爻也。風包雷而交既交，則風中虛而（氣）遊於外矣，風中一虛山之象也，故山又與雷交，非山與雷交也，以既虛之風與雷交也……交雷既畢而風退，其去不遠，猶未甚離于雷耳，故山雷順（漸?）為巽之遊魂；風遊漸遠于雷則漸復其初，以既虛之風神返其宅，又山與風交之象也，故山風之蠱為巽之歸魂。
震宮。雷變第一爻則為地（豫），二爻變則為水（解），三爻皆變則為風（恆），而震之變盡矣。」
（按：巽宮小畜家人益無妄噬嗑五世＋漸遊魂＋蠱歸魂，京房巽宮全合。）

== 0055 八宮八卦次第說下（十·震宮） ==
「雷之與地交非與地交也，地變雷之一爻，此一爻者實風之一爻（?）；雷之與水交非與水交也，水變雷之二爻……雷風恆，震巽之交得其中者也。雷地之豫、雷水之解，則震有餘而巽不足，交之未及者也；地風之升、水風之井，則震不足而巽有餘，交之已過者也。豫也者震巽之交一爻也，解也者二爻也，恆也者三爻也，升也者四爻也，井也者五爻也……」
（按：震宮豫解恆升井五世；游魂當為澤風大過、歸魂雷澤隨，俟下葉。）

== 0056 八宮八卦次第說下（十一·震宮末艮宮起） ==
「故澤又與風交，非澤與風交也，以既虛之雷與風交也，此一交亦非真交也。交風既畢而雷退，其去不遠，猶未甚離于風耳，故澤雷大過為震之遊魂；雷遊漸遠于風則漸復其初，以既虛之雷神返其宅，又澤與雷交之象也，故澤雷隨為震之歸魂。
艮宮。山變第一爻則為火（賁），二爻變則為天（大畜），三爻皆變則為澤（損），而艮之變畫（盡）矣。」

== 0057 八宮八卦次第說下（十二·艮宮末兌宮起） ==
「火之與澤交是以山之二爻與澤交也。天之與澤交非與澤交也……山澤損，艮兌之交得其中者也。山火賁、山大畜，則艮有餘而兌不足，交之未及者也；火澤睽、天澤履，則艮不足而兌有餘，交之已過者也。賁也者艮兌之交一爻也，大畜也者二爻也，損也者三爻也，睽也者四爻也，履也者五爻也。山包澤而交既交，則山中虛而（氣）遊於外矣，山中一虛風之象也，故風又與澤交，非風與澤交也，以既虛之山與澤交也，此一交亦非真交也。交澤既畢而山退，其去不遠，猶未甚離于澤耳，故風澤中孚為艮之遊魂；山遊漸遠于澤則漸復其初，以既虛之山神返其宅，又風與山交之象也，故風山漸為艮之歸魂。
兌宮（起，下葉）」
（按：艮宮賁大畜損睽履五世＋中孚遊魂＋漸歸魂，京房艮宮全合。八宮說下至此僅餘兌宮。）

== 0058 八宮八卦次第說下（十三·兌宮） ==
「澤變第一爻則為水（困），二爻變則為地（萃），三爻皆變則為山（咸），而兌之變畫（盡）矣。澤之與水交非與水交也，水變澤之一爻，此一爻者實山之一爻（?）……澤山咸，兌艮之交得其中者也。澤水困、澤地萃，則兌有餘而艮不足，交之未及者也；水山蹇、地山謙，則兌不足而艮有餘，交之已過者也。」

== 0059 八宮八卦次第說下（十四·兌宮末）＋總論 ==
「困也者兌艮之交一爻也，萃也者二爻也，咸也者三爻也，蹇也者四爻也，謙也者五爻也。澤包山而交既交則澤中虛而（氣）遊於外矣，雷之象也，故雷又與山交……以既虛之澤與山交也，此一交亦非真交也。交山既畢而澤退，其去不遠猶未甚離（?）。澤遊漸遠于山則漸復其初，以既虛之澤神返其宅，又雷與澤交（之象也），故澤雷歸妹為兌之歸魂。
總論。陽不交陰萬物不生，陰不交陽萬物不成，陰陽不交萬物不寧。猶天除（升降?）地，陰陽互易而萬物生焉、成焉、亨焉。大哉易也，其天地萬物之樞乎！天覆地載，乾坤之交也；日往月來，離坎之交也；風雷旋轉，巽震之交也；山澤融結，艮兌之交也。其在人也，有父子之交、君臣之交、夫婦之交、昆弟之交……」
（按：兌宮困萃咸蹇謙五世＋歸妹歸魂，京房兌宮全合；八宮說下八宮俱畢；「總論」即目次卷五「又總論十一」之首——以交樞論貫天人倫。）

== 0060 總論（末） ==
「有朋友之交。天地之數止於五，故爻之交至五而止；人之交亦至五而止。交止於五，不盡其一（?），再交則本體亡矣。交一以至五，爻皆交之正者也；遊歸之交，爻變者也。爻既不得不遊，勢之所不容已也；遊則不能不歸，情之所不容己也。其一遊也又特（待?）而不貪不變，所以善其交也；其一歸也，由散而聚，復命歸根，所以全其天也。天地之所以萬古常交而不缺者，由此道也。五進而後極，其進也漸，進以禮也；一遊而即歸，其退也速，退以義也。此天地自然之道也。知進而不知退者，愚不肖之所以不及也；知退而不知進者，賢智之所以過也。其去遁（遁?）也遠矣。然微而必顯，盛則必衰，交一則酹（爵?）一爻，不如不交之為愈也。然微而必顯、盛則必衰者，天地之定數也；酌盈濟虛，衰多益寡，天地之大公也。持不交之說者，私而已矣，非天地之道也。」
（按：「天地之數止於五故爻之交至五而止」——著录摘句之所本；進退之義「進以禮退以義」與著录「進而知退者賢智之所以通也」相應（文字小異）。）

== 0061 附逆歸說（起）＋識語 ==
「右說本丁卯之夏既成前說之後，復將乾宮卦作遞變，則觀之若（?）自然之次第者。及遍閱八宮又無不皆合其義，與前說迥異而不相背。乃知聖人之精蘊，每未揭於天地者多矣。非是思欲復成一說，而舉筆輒罷者屢焉。戊辰夏，因吾友月川之家，忽得一說，屬（?）焉。然數歲，今舊稿忽得，反覆再玩，若有不愜者。鄙意又推其說如此，視舊說稍加密焉。嗚呼！予方前說之既成，自以為若無餘蘊矣，今又推其說如此，安知後之視今不猶今之視昔乎！聖人之精愈揭愈妙，人心之靈愈用愈出，吾又安能量後此之所至。雖戊辰之去今歲已五六年矣，五六年之中不能推而今始推之，豈亦有定數而能以自主者耶！因誌其成說之由，以見至道之妙，非苦心極力不能得，然亦非皆心力之所能必得也。嗚乎難矣。昔乾隆十八年歲次癸酉夏五月之吉　濡陽後學于濬英文識於福元堂」
（按：**附逆歸說識語紀年乾隆癸酉 1753**——並追述丁卯成前說、戊辰 1748 得新說於月川家；紀年鏈完整：丁卯 1747（八宮圖說上）→戊辰 1748（得逆歸說）→辛未 1751（制圖、跋）→癸酉 1753（附逆歸說、題造化說）→甲戌 1754（序）。）

== 0069 附逆歸說（末） ==

== 0079 河圖渾融一貫說（一） ==
「以來傳述而闡發之卷亦既無餘蘊矣，何容小子更置一言。然竊以為天地之現一理，每露其支而隱其本，非隱其本簡（?）也，玄微無迹可見，在人會悟而自得之耳。後之人因其支而論之，又後之人復因其論之支而論之，支而愈支，愈支愈离，泥先儒之成說，失天地之初意，愚竊惑焉。且夫天一地二、天三地四、天五地六、天七地八、天九十之說，豈果指天地而言乎！不過以其數之奇而屬陽也因而謂之天，以其數之偶而屬陰也因而謂之地。是天地之字不可拘也。至於一生水、二生火、三生木、四生金、五生土之說，又不過以天地始生五行之序言之：初生水一也，次生火二也，再次生木三也，又再次生金四也，未生土五也。故曰一生水二生火三生木四生金五生土。至於成數不過因三為六、四三七為三八為九、五五為十之數，又豈有三為六、四三為七、四四為八、五五為十之謂乎！竊以為圖之一數六數直可作一字六字觀耳，二數七數直可作二字七字觀耳，三八數四九數五十數直可作三八字（畫?）九……」
（按：于氏破天一生水之舊解——奇偶屬陰陽不可拘、成數不過加減之數，直以字畫觀圖，思路灑落。）

== 0080 河圖渾融一貫說（二） ==
「字五十字觀耳。其一二三四五（十?）字也，直可作水火木金土觀耳。是圖中之數亦不可拘也。雖然以此為說，得天地現圖之初意矣，而圖之象數豈畫糟粕煨烬而可廢也乎！間嘗靜觀至道之充塞，細玩象數之布列，而竊思夫天地之初生水也，其時未有所謂火木金土也，天地之中止一水而已，故水一數始。生火也，天地之中有水而有火矣，故火二數始。再次生木也，天地之中有水火而又將有木矣，故木三數又再次。生金也，天地之中有水火木而又將有金矣，故金數四。至於生土，而天地之中有水火木金而又將有土，而五行於是乎全矣，故土數五。
是土具五行之象（?）。內之有水火木金，今觀其象外而中一（?）。自五而增其一也，其六數也；自五而增其二也，其七數也；自五而增其三也，其八數九數也；自五而增其四也（?）。是又外之有內也。且內之水火木金四方相旋，是內外自相合也。外之土北與東並、東與南並、南與西連、西與北並（?），中陰水木火金之生數各共得五數者，四焉（旁注小字難辨）。」

== 0081 河圖渾融一貫說（三） ==
「亦共十。內之生數已具水火木金之理，壹內之成數又外之與內。生數為一者獨無水火木金之理乎！是安得以外之水火木金與內之水火木金相合而為一也。具內之水火木金相合也合於土也，外之土相合也，所以合水木火之間也。是人五行生成渾融而無間也。然則內之五數，其北一即成數之一也，其南一即成數之二也（?），其東一即成數之東三也，其西一即成數之西四也，至其成土……西四即生金之四。其數一則其理即一，則其象何不可從而一。此愚之所以妄易原圖，竟去一十數，蓋欲明天地未（分?）輸之理，不得已而然，故雖蹈滔天之罪而不辭也。若夫水火木金之成數去其五，亦與生數為一焉，是內之一二三四即外之一二三四也，外之五即內之五也……其中一也，中焉者化而為一也，內焉者即一也。由外而內合既密則無迹可見，而未嘗不有盛則有數可尋而無往（?）……」
（按：生數成數內外一貫之數理推演；「妄易原圖竟去一十數雖蹈滔天之罪而不辭」——于氏改河圖之自白，術數家膽識可觀。）

== 0082 河圖渾融一貫說（四） ==
「……不合蒼（渾?）然天地自然之象。其理數之精密以至於此。縮之天地之間渾然一氣，充塞天地無有間斷流行，古今無有止息，不能指其數而區而分之曰此為水之氣火之氣也、此為木之氣金之氣也，又不能區分之曰此為水之方火之方也、此為木之方金之方也。一方之中五行未嘗不有，五行之中五行未嘗不有，此為水之方火之方也（?）。五行之流行，古今無有止息：以木德王、以火德王、以土德王、以金德王、以水德王，寒暑溫涼，是有一定之五行焉；朝望晦弦，是有一日之五行焉。其於人也，有少壯衰老，有心肝肺脾腎，有喜怒哀樂，有仁義禮智，為人倫，為君臣父子夫婦兄弟朋友焉；其於物也，為色之青黃白赤黑、聲之宮商角徵羽、味之酸苦辛鹹，此豈可以數形之以圓象之哉！不得已而圖之以象，則以一南二東三四（?）五土而已矣。不得己而圖之，固不可拘先儒之成說，亦不可泥天地不得已之象而不原天地示人之本意也。學者得吾說而……」

== 0083 河圖渾融一貫說（五·答問） ==
「通之而後再求於先儒之說，則其說亦形下必有之意而不可易者，豈可以盡廢也哉！特由本觀末則其末皆有可取，循末失本則其末皆支離而無可觀。宇宙之間凡理皆然，豈獨河圖也哉！或曰河圖之數生成相配，子之圖何以有生而無成？予曰水火木金其成數固未嘗不在也，即土之成數亦未嘗不在也。且六即一也，七即二也，八即三也，九即四也，十即五也……何俟小子之僭（?）……或又曰河圖之數五十有五，而子之圖其數止於四十有五，乃獲罪于天而有背于先聖乎？予曰：天譬（?）則爻也，聖人則師也，師之業固弟子之所不可輕易者也，苟變之而合道，足以發其所未發，當亦父師之所欣然心許者也。況伏羲之圖主於分，而吾之圖主於合。分則不備其數，合則明其理（?）。不明合則不（?）……其數真理不貫。且河圖之實積全數九十（?）……適得乎則其數亦未嘗不有一當也，而何罪之有、何背之有！曰然則河圖實積全數九十之說猶可得聞與？曰河圖陽數也，陽之理圓，合水木火金之成數而共計之其數三十，亦圓數也，以三十之周而……」
（按：設問答體自辯改圖之非罪——「伏羲圖主分吾圖主合」分合之辨，及實積全數九十之周天說。）

== 0088 洛書真源說（末） ==
「……之理已具矣。夫天地祗此一理也，則天止此一數也，天地止此一數也，則天地祗此一方也。一方而十分之則成百，而其周實三十六數焉。昊天度數之所以必三百六十者，其此之謂乎！再觀其第二周則二十有八數焉，天文列宿之所以必二十八者，其此之謂乎！且除三十六之周而觀其中之積得數六十四，以此知六十四卦之理，乾兌（?）天地該括萬物而無遺也。再除二十八之周而再觀其數之積又得三十六，以此知天地之元氣充塞兩間而無間也。至於第三周其數二十四氣之數焉；第四周其數一十有二辰之數焉；而其外有五，是五也，天地之中有水火木金而有土，而五行於是乎全矣。
中則謂洛書為天地數理之宗焉，可也。故愚竊以為洛書之源實在於此。若夫自書（洛書?）以下而論之，則前人之說備矣。」

== 0089 附觀音解（起） ==

== 0090 觀音解（二） ==
「離居南也。金剛對立。離之對坎也，故其象為中男，尊無二（?），故立也。觀音與金剛為道友——義本夫婦，既言道則不可以夫婦言矣，故曰友。金童居左。童者少男也，先天居西北金也，後天居東北左也。龍女居右（一云玉女）：少女者兌也，先天居辰（東?）地，龍女也；後天居酉地右也；玉者金之義也，色白故曰玉。金童合手，無為之象也。龍女擎珠，金丹之意也。金童者嬰兒（兌?）也，龍女者姹女也。紫竹：紫者黑赤之合也，黑者水，赤者火，水火相濟陰陽會合之意。」

== 0091 觀音解（三） ==
「竹者無心之物，心人之理也，在人有心在天地則無心也。謂水火相濟陰陽會合而出於有意也（?）。白鸚鵡：鸚鵡非人而能言，白者無色無形之意也，無形能言而非人（?）。盎（?）思神也。淨水瓶：淨者一塵不雜也，瓶（平?）音廣大無涯也；又淨盡也，淨盡水陰盡而陽純也；瓶者真如常在，和樂無涯也。楊柳枝：離本東方木地邪（?）其正位也，卯木合而成柳，楊柳陽也；一枝者為金針（?）也，蓋以有金丹之理故也。白蓮：蓮者仙女之象也，白者無色亦無形之理也。落茄（伽）山：上大下小在海中，言不可上也，人莫及之意也，是落伽也是白觀音。蓮也楊柳也淨水瓶也白鸚鵡也紫竹也，總一觀音之變相也。」
（按：觀音解以易丹象數盡解觀音法具——金剛（坎）道友、金童龍女（嬰兒姹女）、淨瓶（陽純）、楊柳（金針）、紫竹（水火濟）、「總一觀音之變相」，三教圖像學歸於一易。）

== 0092 觀音解（四） ==
（頁首旁記：「十八羅漢周天之數其內陰……」小字難全。）
「音可聽而不可觀，能觀色而不能觀音，能觀音者非思神其軌（?）能之。金童龍女者觀音之分也；觀觀音者金童龍女之合也。白衣亦無形之意也，有形象衣服皆非也。送子：人之生祇此真氣之運動也。大悲：千手無所不能也，千眼無所不見也。神無手也，以能言故強謂之手；神無眼也（?），手即眼也，故強謂之眼……眼從手出。化為電神，亦離火之意也。
救十八難：六純陰之數圓之則十八，為周天之年，蓋陰數也，陽吉而凶。救陰者必純陽，故觀音能救諸難也。善財童子五十三參：善財即金童也，以道言之曰善，以金言之曰財，金丹道成諸天……」

== 0093 觀音解（末） ==
「……泰謂隨處（?）方驗驗也。五十三者，八卦錯綜為六十四，除八純卦餘五十六卦，純不涉（?）雜者也，然亦不必盡泰也，故止五十；十三餘尚有五，亦不可泰而得之矣。猶之天數三十六而俗傳止于三十三也。又不泰者三數也，三仙也，仙之理無人參會也，之數止於五十三餘三數以見此理無人參會也。」
（按：附觀音解至此終——十八難配六純陰、五十三參配卦數餘三為三仙無人參會，數理釋佛典盡致；《大真一得》全書（附觀音解）當在此後結束。）

== 0103 河圖洛書位次論 ==
「大傳言河圖曰一、二、三、四、五、六、七、八、九、十，則是以兩相從也。大戴禮言洛書曰二、九、四、七、五、三、六、一（?），則是以三居中。……有六便有七，便有八，便有九。至四十而又居中，順而布之，便成五位者，原洛書之初則有一二三便有四五六便有七八九，層而列之以成四方者。若以陽動陰靜而論，則數起於上，故河圖之一二本在上，三四本在右，六七本在下，八九本在左也；洛書之一二三四五六七八九本自下而上也。於是陽數靜而不遷，陰數動而遷，則成河圖洛書之位矣。如此以陽靜陰動而論，則數起於下。蓋其以兩相從者，如有天地則有夫婦也，有夫婦則有父子也，有君臣則有上下也；以三相從者如有天地則有人也……夫行而婦順，自上而下以用而言者也。」

== 0105 河洛加減乘除數表（二）＋總說 ==
（圖表）「一用二乘奇數得本位之偶數」「一用二乘偶數得本位之偶數」「用六乘奇數得相連之偶」「用四乘奇數得隔二位之偶」「用九乘奇數得相對之奇」諸表（一加九為十三加七為十二六加二為八四加六為十……；九八一／九二七／九三六／九四五諸乘偶數表）。
總說：「右洛書加減之法。四乘十六，其除法除其所得之數。何則？則五者河洛之中數。自比以上由五加一為六，六減五為一，是七與二同根也；五加二為七，五減二為三，是八與三同根也；五加七為十二，五減七為負二（?）……九與五同理同今。用三與八左旋乘奇偶皆得相連之奇偶，可以知七八即二三與六九同理……同根也。五加二為七……皆得相連之奇偶，可以知七即二三即八矣。用二與七右旋乘奇偶皆得相連之奇偶，可以知……合內惟二乘奇數得隔二位之偶數，皆其所得即相連奇位……」
（按：以加減乘除四則貫河洛之數，「五為中數、七二同根、八三同根」為其數理樞要。）

== 0106 河洛同根對位論 ==
「同根之數猶之乎相連也。以一與六乘而皆得本位之奇偶，可知六即一矣；內惟六乘奇數得相連之偶數者，其所得即本位同根之數，猶之乎本位也；用四與九乘而皆得對位之奇……隔二位之偶數者，其所得即對位同根之數，猶之乎對位也。但其得同根之數者何？凡奇乘奇其得數為奇，若奇乘偶不能得奇數而同，故但得其同根之偶數也（旁注：三四九三十四四得四得九諸細注）。所以一六二七三八四九，在河圖則四方之相配，在洛書則正偶之相連，以生數於中五而同根也。數有合數有對數：合數生於五，對數成於十，一六二七三八四九在河圖合數同方而對數相錯，相合相錯皆相減而為五者也……」
（按：合數生五對數成十、相減皆五之數理。）

== 0107 洛書真源＋洛書勾股原圖 ==

（圖二）題「洛书勾股原图」——方圖內疊菱形，標「勾三」「股四」「弦五」「周九十」「二四六（?）」「周三十四」諸數。
（按：以開平方自乘數一六四九釋洛書經緯之位；勾股原圖以勾三股四弦五入洛書，融算學於圖書。）

== 0108 河圖理陳雜方積款說 ==
（旁注積款：八方積數七十二、三陽積數四十五、六八陰數積數四十等。）
「必同來偶既同數……安溪（李光地?）以百方圓而一九二七三四六五十相對互乘俱得百，乃積數之常法，無甚趣味，但此百方之圖與洛書所列之數有奇合者：以四奇位之四方之正中，以四偶數布之四隅而造足無餘欠；再以中觀之，則自中至外八面皆有五數，而中之五又有畧合者，當推之洛書之理之陰著也……數始於一而終於十，十之理已成而一之體仍在。十分為一錢，十錢為一兩，故方其象而以一分數則百數成，以周數之四十布洛書八方之四十而正隅奇偶多寡均配，數有合數有對數：合數生於五，對數成於十……四恰好，斯天地之奇造化之妙不假安排而成者，洛書之所以為洛書於此可以見其真源矣。既成圓而包含理數無窮之妙，任千載下之人竭聰心思之智巧而總莫能罄其底蘊者，總胎於一方哉。」
（按：「安溪」或指李光地（安溪先生）；「總胎於一方」為洛書方圖論之總讚。）

== 0109 河洛未分未變方圖說（起）＋勾股宿度數 ==
（旁注：熱數河圖十位上積，至一周六角重三疊、重二十七除中九、十四角九等細目。）
「乾之奇妙有如此者，而所推勾股之數更見奇妙不可思議矣。間嘗以百方之圖而玩之：周三十六，周天度之所以三百六十也；次周二十八，星宿之所以二十八也；除初周之數餘四卦，所以六十四盡天地之理也；再除次周之宿數餘三十六……其三中四數則五行四德四時四方五常之數也。
河洛未分未變方圖說。河圖五十有五，洛書四十有五，合為一百，此天地之全數也。以一百之全數排方為斜界而中分之，則自一至十者積數，五五相交而成河洛數之兩三角形矣。或曰河圖洛書有定位矣……易大傳之言河圖也曰天一地二天三地四天五地六天七地八天九地十，順而數之，此其未變者也；又曰天數五地數五位相得而各有合，分而置之，此其定位者也。如易卦一每生二……」
（按：周三十六即周天三百六十之縮、次周二十八即星宿數——以方圖勾股推天度宿數，算易合一；「未分未變」本邵雍先天之語。）

== 0110 圖形合洛書為象法之原 ==
（圖）頁頂點陣圖五幅：點數三角（四九六九／五六七數式）、方格點陣、八角網圖二幅。
文：「……乾南坤北離東坎西，其定位者也。不知未變之根，則亦不足以識定位之妙矣。圓形合洛書為象法之原。凡有數則有象，象不離乎數也。萬象起於方圓，而測方圓者以三角，此勾股所以為算之宗也。圓者天之象，方者地之象；天象如環無端，故其象圓也；地之（道?）奠定有常，故其象方也。人受性于天，受形于地。猶三角之形，其心即（?）圓之心。三角求心法：三角自一至四則三其心也，自一至七則五其心也，自一至十則七其心也……至於無數之內惟六角與八角有法之圓形，其自十以後愈多而皆可以求心者視此矣。此三四九所以為方圓之數也……洛書之位一六八居下為天道之下濟……」
（按：以三角求心（幾何重心）法通洛書——西算幾何入易圖，乾隆中期算學東漸之風可見；「圖形合洛書為法象之原」為目次第二篇。）

== 0111 先天後天卦之陰陽不同 ==
「地道之上行，三五六七居中為人道之中，處其數與象亦于圖形乎有合乎。
先天後天卦之陰陽不同。
先天自兩儀而分陰陽：由陽儀以生者皆陽卦也，由陰儀以生者皆陰卦也。先天八卦之序而中分之。後天則卦之已成，觀其爻畫之多寡而命之也。火之炎熱光明其為陽也明矣；澤者水之積濕為陽氣所驅以滋潤萬物者，是亦陽也；水之幽暗寒肅其為陰也明矣；山者土之隆起與地為一體者，是亦陰也。故先天之卦陰陽之象之正也。其變而後天，則火與澤從風而俱為陰，水與山從雷而俱為陽，蓋有由矣。凡陰陽之氣未有不合而成者也，然有感應先後之別：有陽先遇陰者，陽氣在中將散而遇陰則鬱而為雨矣；有陽直騰而上而陰承之則止而為山矣……」
（按：先天後天陰陽分判之異——後天以火澤從風俱陰、水山從雷俱陽，說前人所未發。）

== 0112 先天卦以天地水火為體用 ==
「……陰霾盡而復風息可見也，有陰在中陽必附而散之；薪（?）盡而火滅可見也，有陰在外陽必敷而散之。澗然一氣充塞天地，無有間斷流行，古今無有止息，不能指其數曰此為水之氣火之氣也……此皆主於陰而遇陽，所以皆為陰卦也。乾坤純陰純陽不可變也；雷陽動之始，風陰動之始，亦不可變也。火溫暖澤發散，以用言之則動，然根於陰之燥澤根於陰之濕；以體言之則陰水寒山凝。以用言之則陰然水根於陽之噓而流，山根於陽之疊而起。以體言之則陽，先天之象著其用也；後天之象據其根也。正（?）如仁之發生為陽而其柔和亦可以為陰，義之收斂為陰而其剛決亦可以為陽，陰陽本一氣，互根互行而不悖也。
後天卦以天地水火為體用。造化所以為造化者，天地水火而已矣。易卦雖有八而實維四。何則？風即天氣之吹噓而下交於地者也；山即地形之隆起而上交於天者也；雷即火之奮擊於地中而摶擊發也；澤即水之聚於地上而布散滋潤者也。先天以南北為經而天地居之，體也；以東西為緯而水火居之，用也。」

== 0113 後天卦以天地水火為體用＋先天卦變後天（起） ==
「後天則以天地為體而居四維，以水火為用而居四正。四維者乾坤艮巽也……雷者火之方發，故動於春；及火播其氣則王（旺）於夏矣。澤者水之未收，故散於秋；及水歸其根則王（旺）於冬矣。水火為天地之用，故居四正以司時令也。天氣聯於西北至東南而交於地，易所謂天下有風（姤）也，故乾與巽相（?）；地氣聯於西南至東北而上交於天，易所謂天在山中（大畜）也，故坤艮相對而為地紀。天地為水火之體，故居四維以運樞軸也。天地水火體用互根，以生成萬物，此後天之妙也。若以卦畫論之，則震即離也，一陰閉之於上則為震；巽即乾也（?），一陰行於下則為巽；艮即坤也，一陽敷於上則為兌（?）……是以六十四卦始乾坤中坎離而終於既濟未濟，則知造化之道天地水火盡之矣。
先天卦變後天。火之體陰也其用則陽而天用之，故乾中爻與坤交而變為離；水之體陽也其用則陰而地用之，故坤中爻與乾交而變為坎。火在地中，陰氣自上壓之而奮出則雷之動也。故離上畫與坎……」
（按：天地水火體用論精到；「六十四卦始乾坤中坎離終既濟未濟」本《序卦》上篇終坎離下篇終既濟未濟之義。）

== 0114 先天卦變後天（末） ==
「坎下畫與離交而變為兌。陽感於陰則山出雲，是山者雷與澤之（?）相感也，故震以上下畫與兌交而變為艮；陰感於陽則雷發聲，是澤與雷之上下面相感也，故兌以上下畫與艮交而變為坤。天地相接也。禮登山以祭天，是山與天接也……夫天地水火者一陰陽而已，其情則交易而相通，其體則變易而無定。故先天交變以成後天，莫不各得其位而妙其化，各從其類而歸其根，豈偶然哉！」

== 0115 先天卦配河圖之象＋先天卦配洛書之數 ==
「圖之左方陽內陰外，即先天之震離兌乾，陽長而陰消也；其右方陰內陽外，即先天之巽坎艮坤，陰長而陽消也。蓋所以象二氣之交運也。
後天卦配河圖之象。圖之一六為水居北，即後天之坎位也；三八為木居東，即後天之震位也；四九為金居西，即後天之兌位也；五十為土居中，即後天之坤，周流四季而旺于丑未之交也。蓋所以象五行順布也。
先天卦配洛書之數……戴九履一，左三右七，二四為肩，六八為足，即洛書之數也。先天八卦配洛書之數……」
（頂注紅字：先天卦配河圖之數——乾兌離震坤艮坎巽配九八七六四三二一。）
（按：先儒舊說之輯——「後天卦配河圖」至「先天卦配洛書」諸篇多為節錄先儒成說（出《周易折中·啟蒙附論》一系），與于氏自著諸篇相配。）

== 0116 後天卦生雜卦＋先天卦生序卦（起） ==
「坤濕土生木，故三四次二而為巽，以八數與八卦相配而後天之位合矣。洛書之在邊本一二三四也，其右邊本九八七六也。然陰陽之道，丑未之位必交。洛書二與八正東西南之維，丑未之位也，此所以互易也。以此類之，則先天圓圖之左方坤巽離兌，其右方乾震坎艮，以（?）互而成先天；後天圖之左方（?），以艮坤互而成後天也。
先天卦生序卦。序卦之法以兩卦相對為有相對而不可變者，乾坤坎離頤大過中孚小過是也；其反覆可變者（?），屯蒙以下諸卦是也。皆反覆不變（?）……」
（按：本篇多為節錄先儒舊說（同《啟蒙附論》系）。「丑未之位必交」說洛書二八互易，亦見前洛書根源篇。）

== 0117 先天卦生序卦（續）＋互卦之法 ==
「序卦以之附于坎離既未濟云。先天圖兩相對序卦之根也：乾與坤對，坎與離對，震與巽對，艮與兌對。相交四正之卦相交，離反覆其體不易；四維之卦相交則反覆其體遂易矣。始於乾坤，終于坎離，既定位于上下；中于咸恆，中于損益，終于既未濟（?）。猶之天數三十六而俗傳止于三十三（?）……
後天卦生雜卦。雜卦即互卦也。互卦之法或上去一畫而下生一畫，或下去一畫而上生一畫。互體所成凡十六卦，其陽卦從陽卦、陰卦從陰卦者……四正之卦相交離反覆其體不易……」
（按：序卦雜卦之生成說——相對不易與反覆可變二類；互體十六卦陽從陽陰從陰。）

== 0121 大衍勾股數理論 ==
「卦變陰卦者：乾變兌也，震變坤也……凡陰卦變陽卦者：坤變震艮也，巽變乾兌也，離變坎也……方圓得大衍之數：凡方圓惟徑七者，方二十八、圓二十二，合二數共五十，是大衍之數也。方圓同徑兩數。
勾股得大衍之數：勾三其積九，股四其積十六，弦五其積二十五，合之五十，是大衍之數。衍（行?）之數面，勾股弦三面之積。蓍策之數必以七為用者，蓋方圓之形惟以徑七為率，則能得周圍之整數；句股之形亦惟以三四為率，則能得斜弦之整數。故論方圓周圍之合數則五十，論句股弦之合積亦五十，此大衍之體也。因開方而開之則不盡一數，而止于四十九，此大衍之用也。開方不盡一數，則蓍策之虛一者是已。惟老陽老陰之數與此密合。」
（按：大衍之數五十之幾何釋——方圓同徑相加與勾股三積相加皆得五十，開方不盡故用四十九虛一，融《周髀》勾股入大衍，數理別開生面。）

== 0122 老陽數合方法・老陰數合句股法 ==

== 0123 乾坤策數合周天畫夜度數 ==
「乾坤策數合周天畫夜度數：以地平線分周天之度為二，各一百八十度。日出入暎旦各十八度，共三十六度，以加晝景一百八十度，合二百一十六，則晝度也，乾之策也；以減夜漏一百八十度，則坤之策也（?）……晝夜各行之體數也。大傳曰乾坤之策凡三百有六十，當期之日，故各一百八十者，晝夜平分之數也……開物于寅是亦先天，閉物于亥是亦後天也。故萬物之數萬有一千五百二十，其從陽者四千（?），生氣常勝則為豐年，善類常多則為治世，其消息盈虛之理亦然矣。」
（按：策數配晝夜度數——乾策二百一十六當晝、坤策百四十四當夜，合三百六十當期之日，並以萬物之數千五百二十配消息盈虛。）

== 0131 易例舉要（論卦德） ==
「三畫則三才之道具，而萬象之體立，可以懸卦以示人。然三才各一，則未見三才各具陰陽之理，而尊卑上下、內外進退之變亦有所未盡，故重而為六畫，而後爻變易之事備。
論卦德。凡陽之性健，凡陰之性順。乾健也坤順也，以其純陽純陰，故即以健順名卦。健者動而發，順者靜而翕聚。陽性直上而陰性沉滯。故陽在下為陰所壓則必動而出，此震所以為動也；陽陷陰中則陰之聚而陽為所陷，陽陷莫甚焉，故坎又為陷；陰極於上則得其分而止，艮者止也；陽入而散之，巽者入也。伏者指陰之伏於內也；離也者麗也，陰附陽而麗也。陽氣敷散則陰氣克和，可說故為兌，兌說也。以其用言之，則內剛外柔以接物……」

== 0132 易例舉要（論卦象） ==
「是說道也總而計之，八卦除乾坤外，震坎艮三卦固陽為主，動陷止得名；巽離兌亦以陽入麗說得名，益皆陽為主也。惟坤以順得名似與三女卦異，然順者順乎陽也，未嘗不以陽為主也。推此而言，柔乘剛故不順乎剛，然曰附決則亦剛而散矣。乾健也至健者莫如天，故乾象天而純陽健行居尊；坤順也至順者莫如地，故坤象地至順居卑，而凡純陰至順之物皆足以象之也。
論卦象。乾健也至健者莫如天，故乾象天，而凡純陽健之物皆足以象之也；坤順也至順者莫如地，故坤象地，而凡純陰順之物皆足以象之也。震雷巽風坎水離火艮山兌澤……又為木。此取象之與火相類者也，此獨指離震合體者言。離火也雷則氣之與火相類者也，又在天……以上皆就彖傳大象傳中之所歷指者言，其餘諸象具說卦傳……」

== 0133 易例舉要（論彖傳・論大象傳） ==
「論彖傳。彖傳有先釋卦名後釋辭者，有釋名而兼以釋辭者，有本彖傳言卦德處有用而字者，有轉語詞而字者——兩頭並重，如健而說決而和，言既健而又說、既決而又和也；有用以者，歸重一邊，如文明以止（?）……又文明以健說以動（?）……象傳中言是以故固是推明卦辭所以然之故，然卻非正釋，乃是推體德象類之善，言有可以致此之由也。泥此以解卦辭，恐有認客作主之病。
論大象傳。大象傳所舉兩象，有卦所取者，有雖非名卦第一義而與名卦之義亦甚切者，有非卦名所能盡而意可相發者。君子體象之學約有數端：有探其原者，有防其樊者；其分貼兩象則必先內卦而後外卦……」

== 0134 易例舉要（論爻位） ==
「論爻位。初位三陽位：以陽居之為當位，以陰居之為不當位。二四上位：以陰居之為當位，以陽居之為不當位。貞也。不當位非貞也。亦有當位而不當位而吉者，隨卦義消息也。惟二五兩爻為一卦之中正，未必中而中則無正（?），故兩爻不論當位不當位，率多吉，利之占。其餘諸爻不當位而吉者，亦以剛柔相濟為中也。中義重於正，而卦爻言貞者多而言中者絕少，蓋中不可見，隨處所得，其貞乃所謂時中也。學者當守正以協於中，不可求中而失其正。可與未可與權（?），聖人言貞而不言中，中之義也。六爻初上為事，內外二三四五為當時任事之爻。細分之，則初者人之未仕進者也，避世離群之人也，不臣不友之賢，家之功成身退之人也，避世之事之終也；五君位，四近君之位也；四近而承，三遠而應，皆君臣義合……而不可（?），故多凶危。」
（按：當位說＋「貞乃時中」之論——漢宋易例之融匯，立論平實。）

== 0135 易例舉要（論比應） ==
「論比應。卦所謂應者，初與四應，二與五應，三與上應也。凡應皆陰陽相與，則雖當應位而不取應義，以無相求之情故也。然雖相應而以應義為重者，惟二五兩爻以君臣相得故也。若初與四則取應義，無凶（?）。其間取應義至有同德相應者：如乾二五之見大人、晉六二之晉如（?）、小過六二之遇妣、六五之密雲、大章章之二（?）、訟、豐初四之遇主、聚（?）、初四之遇元夫，皆卦義所重故也。
卦所謂比者，四與五比、五與上比、初與二比、二與三比，皆陰陽相從者也。陰續陽之謂比。陽相從陰，陰相從陽。六四承九五，則君剛臣柔，是恭順；六四乘九五（?），則君柔臣剛（?）……」
（按：比應例——應取君臣相得惟重二五，同德相應諸例（乾二五、小過遇妣、訟遇元夫等）列舉詳明。）

== 0136 易例舉要（論主爻・論卦變） ==
「……乘之義重。以柔乘剛謂其可危也；若以剛乘柔則各得其分而不以乘為義矣。至於三四雖相比然隔體則情不相親，間有取者如豫之（?）、謙之鳴謙、萃（?）之（?），皆卦義所乘（承?）或卦主在焉故也。
論主爻。卦必有主爻：有主卦之主，有成卦之主。卦之主五居君位是也；成卦之主則隨卦分別，如剝夬上（?）、始復初之類。六爻之占大約視卦主遠近向背好惡為吉凶悔吝之淺深。
論卦變。卦之爻變則用，不變則不用。故爻言九六而不言七八。是卦之爻變則用，卦之變不必指卦陰陽之上下往來為卦變也。蓋上下往來但就陰陽爻之在上在下在外在內而言，熟玩彖傳合之爻詞則其義自見。」

== 0137 易例舉要（論取象・讀易指要，全冊某篇之末） ==
「論取象。卦爻之象自有所從來而先儒說者多鑿：大鉤（?）本卦不得求之變卦，更求之納甲錯綜飛伏，附會莫可究竟詰，而於理毫無所得。以程朱傳義一切掃（?），而（?）……求象固不可泥，觀玩者又烏可謾然無所用其心乎！竊象自在本卦爻之中。右所錄不知所出自何人，疑夏（?）震軒先生（?）之所作也。
讀易指要。學者要明易理，須先將伏羲畫卦次序方位、文王八卦方位及先後天方圓諸圖反覆記令其曉然，再將說卦傳看，記得極熟，然後讀易方有入手處。至其每讀一卦，且先看卦辭、彖傳、大象，然後看其每爻爻辭，看明合在一處成一片……看明令合在一卦成片，則各卦各爻其義已可得其根。何（?）歷落分明，各有下落，所以名卦之義已可得其梗概……」

== 0138/0139 讀易指要（長文） ==
「概（?）於是重讀卦名，連讀卦解，其探索卦辭必要令其字在卦名內生出不攙侗，然後讀彖傳則細別其……句是卦象那一句是卦德，是分釋卦辭；渾釋卦辭是正意是旁意，是推廣意。認定第一句為名卦之本而詳玩其言卦體句蓋也，一句乃一卦主爻所由定。而六爻吉凶俱以此為斷例不可忽也。其觀大象也須見兩象之意無不包，名無不當而設，身處地無在非反身踐履之學。而所以上溯伏羲作易之源亦於是乎在，皆讀易之法也。
總讀爻辭先將此爻之當位不當位、上下內外之地、承乘應有善惡與否，與比卦之最小（?）合否，為（?）之二字又爻辭之根也。其讀爻辭也先令文義分明道理平實，亦令字字在爻位內生出，得當卦之時而所值之爻則應有如此之象占。於是復其象之所自來：象有在本位取者，有在應比之位取者，有在互體取者。精思熟玩務要確當，自然有不得者寧闕其（?）。
疑勿踏穿鑿之病。至於吉凶悔吝無咎利不利等占，乃文周與民同患之意，其輕重不爽錙銖，如操權度以度量事物，又如法律之斷案，須允協於心方已。至於夫子彖傳其辭甚簡卻不可忽畧或深探本源明指德位以見象占之有自來，或示人以改過遷善之門……
有自來或示人以改遇遷善之門而却所變計須隨在研究。坎離之變為既濟未濟既濟也……地（?）剝也風山漸也地雷復也風天小畜也天風姤也澤天夬也山地（?）……故學易者當以虛心探索其門予總觀（?）……二例一則一定不易一則移步換形……妙無窮誠天地自然結構之理數也（與前重出?）。宜守不宜守不宜字之貞在上則當用小（?）貞之道當蒙之時為師則當（?）包蒙之吉……在家人則尚剛而義畫（?）於反身在旅則尚柔而義極於（?）射。避（?）則以無繫累為善。晉則以勿恤得失去為歸。比皆確當之理極至之詣。凡人生平所值之時所處之位，不論窮達貴賤，總有一確當之理至極之詣，即向易中尋取準繩，庶不至惑於歧途，且不落第二層地位步矣。而其觀象玩辭……」
（按：讀易指要為全冊中最完整之讀易方法論——卦名連讀、認主爻、觀象玩辭、於時位中求「確當之理至極之詣」，《易》之用歸於人生踐履。）

== 0140 讀易指要（末） ==
「……亦須每卦每爻求所處之道，以為立身行道之本。將束（?）任天下之重、應無窮之變，亦坦然行之而無疑，所謂既有典常，此其一端也。移步換形者，如乾二五皆利見大人，而有德有位與無德無位者所處不同；如坤初六履霜而（戒?）……卦本以陰長之漸而有位者處之便當退，小人之戒。無位者處之即以遇（?）人欲之萌；比之內外比本臣子之事也；而學易者即可用以取友親師；家人之中饋富家本女子之職也，而學易即可以用修業蓄德。推之諸卦皆然。

== 0142 易論摘析（二） ==
「卦者時也，爻者適時之變者也。時有否泰，故用有行藏；卦有小大，故辭有險易。不易者（?）……應者同志之象也；位者爻所處之象也；承乘者順逆之象也；遠近者險易之象也；內外者出處之象也；初上者始終之象也。……象者出意者也，言者明象者也。得意忘言（象?），得意（?）者也。文苟在健何必要乾乃為牛，義苟應健何必坤乃為牛！而或定馬於乾，案文責卦，有馬無乾，則偽說滋漫，難可紀錄矣（旁注：互體不足遂及卦變，變又不足推致五行，一失其原，巧愈彌甚）。縱復或值義無取，蓋存象忘意之由也。忘象以求其意，義斯見矣。

（按：此葉全輯王弼《略例·明象》「得意忘象」「定馬於乾」名論，頂注小字為于氏辨語。）

== 0144 易論摘析（四） ==
「易以形而上者說在形而下者上；春秋以形而下者說上（?）。形而上者是陰陽交於陰陽。是卦圓上底（?）。如天地定位、山澤通氣，勢是也；是變易是老陰老陽變少陰少陽；比是澤通氣（?）。占筮之象如寒暑晝夜屈伸往來者是也。卦畫既立，則有吉凶，益以陰陽往來錯綜於其間。時有當否，而卦有吉凶。凶見矣，故曰八卦定吉凶，吉凶生大業。大抵天下之道只是善惡而已，但所居之位不同，所處之位既異，則其幾甚微，只為天下之人不能曉會。所以聖人因設占筮之法以曉人，使人居則觀象玩占，不違于是。是書虞夏商周皆用之。其法若粗淺，然隨人賢愚皆得其用。雖是定象有定辭，皆虛說。此簡要人如此處置，初不黏著物上，故一卦一爻足以包無窮之事，但看人如何用之耳。」
（按：占筮虛設說——「一卦一爻足包無窮之事但看人如何用之」，全書讀易觀之總結。）

== 0145 評象數義理論（承摘析而作之評？） ==
「易如鏡相似，看甚物來都能照得。如所謂潛龍，只是有箇龍德而隱，便是就事上指殺（?）說來，人都使得。程朱傳義一切都說了。須知得他是假托說，是包含不盡；象在此也，無（遷?）也。
易之有象，其取之有所從，其推之有所用，非苟為寓言也。兩儀諸儒欲究其所從，則泥滯而不通；王弼以來直欲推其所用，則又略而無據。二者皆失之一偏而不能闕疑之過也。如乾稱（?）馬、坤稱牛，說卦有明文，而乾馬坤牛順（?）在物有常理矣。乃反為乾是皆不可曉者。是以漢儒創為互變飛伏諸法以為……常理矣乃亦有馬而無乾、離有牛而無坤，乾龍坤牛強求諸法窮矣。馬反為乾（?）……推其所用則又略而無據，此皆失之的一偏而不能闕疑之過也。漢諸儒必欲究其所從，則泥滯而不通；王弼以來直（欲?）……王弼程子破先儒膠固之見。人事之訓戒何必苦求以求之哉！故王氏程子破先儒膠（固?）……」
（按：此篇評王弼「得意忘象」與漢儒互變飛伏皆「失之一偏」——象不可泥亦不可廢，「人事之訓戒何必苦求」收束，與 0083 河圖「管郭之學」之辨同旨。或為于氏自撰之評。）

== 0148 乾坤二畫・任釣臺讀易法（起） ==
「乾坤二畫。
任釣臺讀易法。先生諱啟運。
八卦只八卦而天地萬物無所不包。舉天地水火山澤風雷，亦舉最大者以象之耳。予曰乾為天為父為金……大是極細也，極靈是極蠢也，是形色。千態萬狀觸目都是八卦，便觸都是太極。太極便是八卦，八卦便是太極。人得見太極（?）本是太極無極（?）。在此易沒要緊。愚道最吃緊處正在此。八卦既定便各有一定之性情、一定之德器、一定之才具。」

== 0149 任釣臺讀易法（續）・互卦卦變錯卦例 ==
「互卦如坎陰也，互震則出互離明（?）；離明也互坎則幽。互巽亦焚葢（?）。入互體則物離其德亦轉，用之為補救則是，用之為疑沮則非。故曰離物撰德，辨是與非，則非其中爻不備。觀象既得乃可玩辭。大約卦之名從兩用上定，象之辭從本象及互象上定，爻之辭從二用及互象上定。文象所指有未明者，文必指明之。如此曰利建侯（?），公于（于?）初，明之蒙曰童蒙求我，公于五明之，我而卦主在二矣。損曰可貞元吉無咎有攸往，歷明之他卦即有未明指（?）者，其此之謂乎……
錯卦之例（此即對比明見）：若否泰之初皆拔茅茹，始（?）萃升之……」
（按：任氏法——卦名從兩用上定、象辭從本象互象上定、爻辭從二用互象上定；「離物撰德辨是與非則非其中爻不備」本《繫辭》。）
