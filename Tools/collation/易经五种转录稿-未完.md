== 0004/0005 書名葉＋序（起） ==
書名葉大字：「玉京山人著　易鈔五種　楊卓訂」。左下鈐朱印「哈佛大學漢和圖書館珍藏印」。右上一舊簽條倒貼，反字可辨：「世有表章此書者（?）急宜刊去識者自能辨之　老初（?）徐棟謹志（?）」。
序（起）：「道無言也，聖人不得已而有言，非聖人之言也，天地之言也。道無象也，聖人不得已而有象，非聖人之象也，天地之象也。凡出自聖人之手而適（?）如其自不假思索，而莫知其所以然者，蓋莫非天地之借（?）徒現於龍之身、龜之背，聖人從而則之者也。大真先生遊心象外，思入元微，其所造之（?）……」

== 0006 序（承） ==
「……所得而窺測者，獨其所著大真一得。蓋出自創見，獨抒心解，以發古聖之精，以洩天地之秘。豈非宇宙間一快事哉。第閱之者未數（?）思臥，益以庸俗之目對微妙之理，宜其格格；如而粗通大意，亦未嘗無管窺之一二。而以卓之頑鈍不敏，乃能詳閱數周，雖其精微幽（?）……先生亦許為知已而樂與講論不置也。〔自）抒於乾隆之丁卯，成於乾隆之癸酉，前後六七年間，或數年而無一字，或傾刻而數百言，汨汨滔滔不加點竄，自爾成理；暢有苦心焦思而不能得者，忽然得之一旦，在（?）先生亦不解其何處收蔵如許也。然則大真一得一書（?）亦天地欲洩此理於今日，而特假手於先生而出之，豈（?）先生之言、先生之象子（?）……」
（按：序自述「抒於乾隆丁卯、成於乾隆癸酉」——乾隆丁卯 1747、癸酉 1753，前後六年餘；「卓」自稱即楊卓（臥雲子）。）

== 0009 目終楊卓再識＋造化太極圖說（起） ==
「目终。右书十馀卷，阐惟八宫图说上成帙（?），又天图说先天图说观音说又次，造化太极图说馀俱成（?）。而今之序如右，盖以理为次而不计其岁月之先后也。化太极图虽非出于古圣之手，而太极之所有是形者，于此始见其图之出于自然而得其所以然，故以列说篇首。观音说则因俗谈而阐推之，虽亦未始非妙理，而意杂羌（?）氏，益亦游衍之戏笔耳，故以附诸篇末云。杨卓再识。」
正文起：「造化太极图说　玉京山人于濬英著」
「子曰动静无端阴阳无始。曰剥之为卦也，诸阳消剥已尽，独上九一爻尚存，然阳无可尽之理，尽于上则生于下，无间可容止息也。阴亦然，圣人不言耳。窃以此两言泄尽造化之机矣，因图以明之，而又为之说，以俟夫知道之君子赐针砭焉。乾隆癸酉年春二月题。
太极者道也，形而上者也。形而上不可以象（?）……象之者借器以象之而已（?）」（承 0010）

== 0010 造化太極圖說（二） ==
「亥為陰之極，陽之盡也；巳為陽之極，陰之盡（?）……盡于此則生（?）于此。畫之時即生之時也。造化之機，其來有漸，不遽有也；其去有漸，無不遽無也。復之一陽一陰之成也，姤之一陰一陽之成也，然非思無而成也。故陽始于小雪，陰始于小滿。剝之一陽之存也，夬之一陰之存也。至於坤猶有未盡，蓋剝之陽故必至小雪而後為剝之盡；至於乾猶有未盡，盡剝之陽故必至小滿而後為夬之盡。
陽去為剝，不必戌也；陽來為復，不必子也；陰去為夬，不必辰也；陰來為姤，不必午也。然則何以為乾坤？曰動靜無端，陰陽無始者，理之于一也；復姤各擅其盛者，分之殊也。是故泥分之殊而忘理之一者，非也；執理之一而疑分之殊者，亦非也。觀復之一陽生于小雪，則臨之二陽生于冬至也，子知（知子?）矣。則泰之三陽生于大寒（?），大壯之四陽生于雨水，夬之五陽（?），乾之六陽生于穀雨也可知矣。」
旁注：「陰陽之始於春秋……云始於巳亥，非聖人……」
（按：以十二月卦（十二辟卦）配節氣言陰陽消長——復一陽小雪、臨二陽冬至、泰三陽、大壯四陽雨水、夬五陽、乾六陽穀雨；陽盡於亥、陰盡於巳之數術化以太極。）

== 0011 造化太極圖說（三） ==
「道不離器，亦不滯於器中也；滯者自滯也。往古來今千萬載，一太極也；上下四方呼吸間，一極也。然遠而不可見也，微而不易察也，可得而易見者，其一歲乎！一歲之中寒暑迭禪，太極之象也。然寒於何日，其界不可指也；暑於何時，其節不可畫也。氣不可畫，其節也；而理可指，其界也。
先儒於六十四卦中取復、臨、泰、大壯、夬、乾，始遯、否、觀、剝、坤十二卦，以象一歲陰陽消長之機，未嘗以此明太極也。間嘗竊取見焉。（邵?）子之意合而圓之，而所謂一歲有太極之理者，思（息?）焉。
人知陽之始於春也，而不知陽之始于子也；人知陰之始于秋也，而不知陰之始于午也……」
旁注：「陰陽之始於春秋……云始於巳亥，雅非聖人……乾隆知之」

== 0012 造化太極圖說（四） ==
「觀姤之一陰生于小滿，則遯之二陰生……可知矣。則否之三陰生于霜降……坤之六陰……陽極于巳，而一歲之大暑乃在未申，陰所逼也，逼盡陽于地上，故其暑愈猛，至于酉陰始出地而暑退矣。陰極于亥，而一歲之大寒乃在丑寅，為陽所逼也，逼盡陰于地上，故其寒愈烈，至于卯陽始出地而寒退矣。
豈惟一歲，一月之中有太極焉，朝望晦弦一陰陽四時也；一日之中有太極焉，晝夜朝夕一陰陽四時也。一歲而外，安知數十年中無一陰一陽乎？安知數百年中無一陰一陽乎？安知數千年中無一陰一陽乎？安知數萬年中無一陰一陽乎！
豈惟天地，人身之中有太極焉，少壯衰老一陰陽也，窮達通塞一陰陽也，憂樂相尋一陰陽也。豈惟一身，一家之中有太極焉，盛衰興敗一陰陽也，治亂存亡一陰陽也。豈惟一家，一國之中有太極焉……」
（按：太極遍在論——由一歲而月、而日、而數萬年，由天地而身、而家、而國，層層推衍。）

== 0013 造化太極圖說（五） ==
「祗此一氣，近在一息呼吸，遠在天地終始，今與道為體者，命之所以流行而不已也。一氣二分之為四時，四分之為十二月，十二分之為二十四氣，二十四分之為七十二候，七十二分之為三百六十日，脈絡分明，井井不亂者，分之所以一定而不易也。
剝者落也，惟恐其落，故於其將落也名之曰剝，蓋惜之也。復者返也，惟恐其返，故於其方返也名之曰復，蓋喜之也。古聖人之扶陽也如此。
夬者決也，急欲其去，故於其將去也名之曰夬，決之使去也，快之也。姤者遇也，惟恐其來，故於其方來也名之曰姤，蓋曰又遇其來也，憂之也。古聖人之抑陰也如此。
剝而必復，復而必剝，夬而必姤，姤而必夬……者，數也，命也，天道也，人之所無如（?）何者也，聖人於此罕言焉。剝而惜，復而喜，夬而快，姤而憂者，理也，性也，人之所當自盡者也，君子於此乾乾焉。」
（按：卦名訓釋寄扶陽抑陰之情——「天道罕言而君子自盡」，理一分殊之旨。）

== 0014 造化太極圖說（末） ==
「古之君子其治國也，安不忘危，其治家也（?），忘食其治身也。是故几杖盤盂皆有銘焉，動容周旋必以禮焉，所以養善於未形、絕惡於未萌也。望道未見，曾子南容之所以賢也。書曰吉人為善，惟日不足；凶人為不善，亦惟日不足。召烈（?）曰勿以善小而不為，勿以惡小而為之。子思曰莫見乎隱，莫顯乎微，故君子慎其獨也。又曰戒慎乎其所不睹，恐懼乎其所不聞，君子之道盡于此矣。詩云維天之命，於穆不已，蓋曰天之所以為天也；於乎不顯，文王之德之純，蓋曰文王之所以為文也，純亦不已。聖人之道盡于此矣。」
（按：卷一造化太極圖說以慎德收束——由天道之不已轉出君子慎獨之修，中庸結穴。）

== 0018 太極八卦一體圖說（起）＋題詩 ==
題詩（九句）：「鬼聖揭（撼?）其委　後聖探其端　千年有大真　鑒破渾淪團　淵微縱橫出　能分復能連　機竅透劫前　昊天洩妙理　又假玉京山」。
說文：「太極八卦一體圖　玉京山人于濬英著。太極者陰陽消長之機也，理至此無以復加矣，以其無理之可名，故強名曰太極。孔子曰易有太極，是生兩儀，兩儀生四象，四象生八卦。道之至極，先聖每不欲盡言之，〔孔子〕是說是有太極而又有兩儀，又有四象，又有八卦，豈有是理哉！止此一○，分之為〔陰陽兩半圓〕則為兩儀，又分之為〔四分圓〕則為四象，又分之為〔八輻圓〕則為八卦，推之六十四卦，其○一也。」

== 0019 太極八卦一體圖說（二） ==
「是八即四也，四即兩也，兩即一也。然則孔子之言非乎？曰孔子之說不得已而舉其似，形而下之言也；吾之說不能思而露其真，形而上之言也。一元之氣陽長陰消、陰長陽消，古人強為〔太極圖〕以明之，又列之以八卦，可謂竭揭其密以示人矣。不如是，人不知八卦為太極；然如是，則人又泥太極之外有八卦，甚定理之難明也。太極八卦之渾淪，統一之道也；分殊之道也。
以〔太極圖〕分之：正北純陰之象也，東北陽初升陰盛之象也，正東純陽冒之象也，西南陰初升陽猶盛之象也，正南純陽之象也，西北陰長陽消之象也。
八卦之各為其體也。四分之則南皆為乾、北皆為坤、東皆為離、西皆為坎；又四分之則東北皆為震、東南皆為兌、西南皆為巽、西北皆為艮。八卦之互為其體也。」
（按：「八即四、四即兩、兩即一」統一分殊之辨；太極圖黑白配置配先天卦象（正北純陰坤、東北陽初升震、正東純陽離、東南陽猶盛兌、正南純陽乾、西南陰初升巽、正西陰盛坎、西北陰長陽消艮）。）

== 0020 太極八卦一體圖說（三） ==
「論四象則南為太陽、北為太陰、東為少陽、西為少陰。以〔四分圖〕論兩儀則南為陽而北為陰。以〔八輻圖〕論兩儀則東南為陽而西北為陰。以〔太極魚圖〕論兩儀則……東南為陽而西北為陰。此又兩儀之互為其體也。乾一兌二離三震四巽五坎六艮七坤八，此八卦自然相次之第也。
乾兌離震為陽之卦，而太極之位則到於東南；巽坎艮坤屬陰之卦也，而太極之位則到於西。陽以壯為貴，故先盛而後微；陰以少為美，故先微而後盛。陽自南而東自南而西而北，上北下也。以上下觀陰陽並立之象也。
陽似逆陰似順，陰陽顛倒交互之象也。陽以動為本，靜則逆而動則順也；陰以靜為本，靜則順而動則逆也。然其逆也以隨乎陽而動也，動隨乎陽，其逆乃其所逆也……」

== 0021 太極八卦一體圖說（四） ==
「〔八卦〕以順也。八卦八方方其外者中含一，一者九也，八之所拱也。乾一與坤八合一與八合九也；東北震四與西南巽五，四與五合九也；東南兌二與西北艮七，二與七合九也（〔洛書對待合九之義〕）……卦三畫，八卦共二十四畫（陽十二陰十二），然陽□一而陰□二，再加之得三十六，此三十六之散見者也。
上天地萬象森然羅列古今，不貴安排。四時行焉，百物生焉，上天何言哉！予何言哉！孔子曰予欲無言。夫無言之為妙，生天地乃是真竅。自然之道無為之妙，天地合其德，日月合其明，風雷合其變，山澤合其潤。聖人因萬物之宜，順萬物之能，各得其所，乎天成無為而治天下太平。唐虞而後惟孔子乎！無意無必無固無我，渾然一理泛應曲當，老者安之朋友信之少者懷之，因物付物己不與焉，故其……」
（按：洛書對待合九、二十四畫加至三十六之數理；引論語予欲無言、無意無必無固無我以贊無為之易。）

== 0022 太極八卦一體圖說（末）＋後天八卦方位圖 ==
「告景公曰君君臣臣父父子子。嗚乎至矣，蔑以加矣。君子不以私喜，公不以私怒（?）。敬以承天，義精仁熟，萬復本原。太極在我身，具先天八面玲瓏，曉月落萬川。」
（圖）題「後天八卦方位圖」——離上坎下、震東兌西、巽東南、坤西南、乾西北、艮東北。圖下說：「乾坤離坎先天之正方也；震兌巽艮先天之隅方也。正方居正方者乾坤是也；隅方居正方者震兌是也；正方仍居正方者離坎是也；隅方仍居隅方者巽艮是也。」

== 0023 乾坤六子之圖＋後天八卦圖說（起） ==
（圖）題「乾坤六子之圖」——乾父☰坤母☷居上，震長男坎中男艮少男、巽長女離中女兌少女列下。
圖下引《序卦》：「有天地然後有萬物，有萬物然後有男女，有男女然後有夫婦，有夫婦然後有父子，有父子然後有君臣，有君臣然後有上下，有上下然後禮義有所錯。」
正文：「後天八卦圖說　玉京山人于濬英著。
萬物未生，生於天地；萬物既生，生於萬物（?）。既在男女而在父母，無事矣。男女未生，道在父母；男女既生，道在男女，而父母無事矣。天地之形東陽而西陰，陰陽之理陽外而陰內（?）。內之勢外進而內退。父母無事，怡老居休，故退處於無為之鄉。」
（按：卷三後天說以父母生子喻乾坤生六子、道之遞嬗退休。）

== 0024 後天八卦圖說（二） ==
「以天地陰陽之理觀之，戌亥之間陰之極而陽之絕也，陽絕無所用其陽，故乾之老也，居之純乎無為也。未申之間陽之極而陰之絕也，陰絕無所用其陰，故坤之老也。然未申之氣雖陽而已陰（?）……蓋陽尊而陰卑，坤之體雖無為而心則未嘗無為（?），猶之父母同老而父母未（?）能全逸也。天老陽而地老陰，火少陽而水少陰。老陽退而少陽代，少陰退而少陽（陰?）代。離之所以居乾位也，坎之所以居坤位也。
離女也亦少陰也，老陰之變必少陰，故乾之後為離。坎男也亦少陽也，老陽之變必少陽，故坤之後為坎。坎中男也，長男經營四方，常居于外，不可主家政，故主家政者以中男（?）。離中女也，長女已適人，不可與家事，故與家事者以中女。震之正東，離父母最遠，長男居外之象也；巽之東南，離父母亦遠，長女適人之象也。」

== 0025 後天八卦圖說（三） ==
「艮隨長男於外，十年出就外傅之象也；兌依父母而居于內，女子十年不出之象也。離坎之主政非離坎之定位也。有乾坤則坎離為男；如無乾坤則坎離為父母矣。坎離為男女則主事；坎離為父母則坎亦將退休矣。坎離退休則又有坎離之男女主事矣，此生生不息繼續無窮，世運嬗代之常道也。而長男長女之為父母，坎于此可推矣；而少男之為長男、少女之為中女（?）如為長女為母，又可推矣。
陽絕西北亦生西北，酉者陽之原也，乾之居此，反本還原之理也。陰本絕東南而生於東南，再生于西南者，陰再生之源也，坤之居此亦反本還原之理也。坤之原必再著母以道人（?）……二而後嫁，非始生時也……申土之（?）並坤也，配合而成之象也，今已歸原矣。」
（按：後天卦位配人倫長幼家政之喻——出就外傅、女子十年不出用《禮記·內則》成語；生生不息世運嬗代收束。）

== 0026 後天八卦圖說（四） ==
「莫高于山，山之上天而已，故先為山而後為天。大地之始由風吹而堅（墾?），故先為風而後為地。火為氣之先，附木而後行于天；水為氣之質，先生（金?）而後行于地。雷火之聲也，雷之發也必先電，故先火而後雷。澤水之聚也，故先水而後澤。澤為水草之叢，風之所起也，故先澤而後風。雷于空近之者為山，故先雷而後山。
先天之天地，理也；後天之天地，象也。先天之水火，水火之氣也；後天之水火，水火之質也。先天之雷，無形之風雷也；後天之山澤，有形之山澤也。……乾坤讓離坎而退居艮巽之位，艮巽依方而同避于坎離之里。則艮巽有相向之理。先天之巽從天之坤也，則坤與艮有相連之勢；先天之艮後天之乾也，則乾與艮有相連之勢。巽艮居震兌之位，則震兌不得不移；離坎之位，則震兌又有相向之理焉。合觀之，縱橫成行（田形），九宮之象也。」

== 0027 後天八卦圖說（五） ==
「先天無為，天道也；後天有為，人道也。無為之道體也，有為之道用也。先天天地水火雷山澤，一定不移對待之理也；後天乾坤坎離艮巽震兌，變動不居流行之理也。先天之形四方相向，其象方而大；後天之形南北相向，其象順而簡。先天即理而道，其常，天地之常經也；後天即事而道，其變，古今之通義也。
乾坤離坎先天南北東西相向，此理勢之已相連者也。乾坤讓離坎而退居艮巽之位，艮巽依方而同避于坎離之裡，則艮巽有相向之理……合觀之縱橫成行，九宮之象也，縱橫皆申之象（?）。」
（按：先天後天之辨——理象、氣質、無為有為、體用、常變五對偶，為後天說之綱；「九宮縱橫」承前八卦九宮圖。）

== 0028 後天八卦圖說（末·後序） ==
「男女各有其分，長幼各有其職，老者尊者慈，而身無不脩矣，而家無不齊矣，推之而國治矣，天下平矣。勢位不可久居，功名不可久戀，知足不辱，知止不殆。孔子曰及其老也，戒之在得。養尊處優，每享期頤之樂；怡神休氣，償還少壯之勞。蓋觀于乾坤而知之。恭承先志，祖宗之法度不可更；敬慎貽謀，子孫之驕淫不可啟。蓋觀于離坎而知之。未衰不預（?），當身不辭，已過不貪，天下事興亡共為之，公莫公于此矣。問臻此（?）君子曰：有克己而已矣。未衰不預，姑求其志；當身不辭，竭力盡職；已過不貪，遂志樂天。人也，理也，勢也，一也。一者何也？曰仁也。克己行仁，由勉而安，渣滓消融，庶幾自然。身居後，天心是先天。曆筭（?）先生曰若問先天一事無，後天還得著工夫。蓋而已。心知其意而特隱而不發，不欲輕泄，以俟後人之參悟而自得也夫。出震齊巽之說，既不易解，而先儒之言道者……」

== 0029 後天八卦圖說跋 ==
「又未見其詳於（?）……也。予何人斯而敢云簽（筮?）先儒之所述，陰擄臂取于至道之途（?）。嘗竊取其說而推之，但覺寵（?）無一之妙趣，若管窺于萬意……立象之盡意，恍若管窺于萬性……吾向之疑而久（?）……吾向之疑耽（?）而一旦偶（?）然假手于吾（?），與闡發，遂能使……而聖人之意否耶（?）……說為燕說也，吾之罪大矣。願傳之（?）明貴造之儒賜之鍼砭，正其舛訛，不至上誣先聖，下誤後學，人也則幸甚。
乾隆十六年歲次辛未秋七月上浣吉日　瀛陽後學于溱（濬?）英文明氏敬跋」
（按：**跋落款乾隆十六年辛未 1751 秋七月**，自署「瀛陽後學于溱（濬?）英文明氏」——作者籍里瀛陽（直隸河間府一帶），名濬（溱?）英、字（號）文明，與卷端「于濬英甫著」合；跋自謙成書恐燕說誣聖，請儒者鍼砭。先後天圖說至此完，紀年得四：辛未制圖、辛未跋、癸酉題說、甲戌序。）

== 0032 八宮八卦次第說上（起）＋先天方位表 ==
（圖表）正南乾為天、正東離為火、西南巽為風、西北艮為山；正北坤為地、正西坎為水、東北震為雷、東南兌為澤——先天八卦方位表。
正文：「八宮八卦次第說上　玉京山人于濬英著。易者爻易之義也。伏羲既作八卦，復從八卦陰陽互相交易而得六十四卦。天與地相對也，故天與地互，地亦與天互；火與水相對也，故火與水互，水亦與火互；風與雷相對也，故風與雷互，雷亦與風互；山與澤相對也，故山與澤互，澤亦與山互。此相對者有相為交易者也。」

== 0033 八宮八卦次第說上（二） ==
「此四正相對與四隅相對為交易者也。以天地相對者逆于火水而歸于天地；以火水相對者逆于天地而歸于火水；以風雷相對者逆于山澤而歸于風雷；以山澤相對者逆于風雷而歸于山澤。
天地火水居四正者也，風雷山澤居四隅者也。以天地火水為經，則以風雷山澤為緯；以風雷山澤為經，則以天地火水為緯。
天陽而地陰，火陽而水陰，天與火皆陽類也，地與水皆陰類也。風陽而雷陰（?）……地水雷澤皆陰類，故緯地者以雷澤……以澤雷緯雷者……天遊于火，火亦遊于天；風遊于山，山亦遊于風……陰與陰從其類也，陽與陽各從……」
（按：交易說——四正四隅相對、經緯互緯、陽類陰類相從，釋六十四卦之所由生。）

== 0034 八宮八卦次第說上（三） ==
「其類也。地遊于水亦遊于地，雷遊于澤亦遊于雷，亦陰與陰各從其類也。天與風陽之純者也，純與純相合，故天先與風交而後及于山；火與山陽之次者也，次與次相得，故火先與山交而後及于風，山亦先與火交而後及于天。地與雷陰之純者也，純與純相合，故地先與雷交而後及于澤；雷亦先與地交而後及于水。澤與水陰之次者也，次與次相契，故水先與澤交而後及于雷。
陽無陰不成，故天火風山必以地水澤相互而成八卦，陽中包陰也；陰無陽不生，故地水雷澤必以天火風山相互而成八卦，陰中包陽也。天火相遊，地水相遊，正方仍遊正方也。」

== 0035 八宮八卦次第說上（末）＋于濬英自識 ==
「風山相遊，雷澤相遊，隅方仍遊隅方也。余于八宮六十四卦見其參差錯亂配合不倫（?），又見卜易者有遊魂歸魂之說而不能解。因思是必有其理。於是將乾卦一宮錯綜處畧加位置，忽成一圖。及徧閱八宮皆如此。遂將八宮各作一圖，列其次第。近復玩之，不得其蘊。乃知聖人所作，真有如天地設，確乎其不可易者，而遊魂歸魂之義亦遂不言而出矣。第八宮本以天地火水與風雷山澤互而成卦，則其次第固自有一定。不知後賢何故以乾兌離震巽坎艮坤為次，或又以乾坎艮震巽離坤兌為次，使聖人畫卦次第之妙湮沒而不彰。夫後天之學與先天各自為說，即先天八卦方位之序亦第就其來往順逆而言耳。今奮為此圖與說，不敢曰闡千古之秘，第欲自明其鐵（砥?）云耳。
乾隆十二年歲在丁卯夏五月　濡陽後學于濬英文明謹識于思誠堂」
（按：**圖成紀年乾隆丁卯 1747**——八宮圖實為全書最早之稿（序稱丁卯成癸酉者合）；籍里自署「濡陽」（0029 跋「瀛陽」異文待考）；斥後儒乾兌離震、乾坎艮震兩種卦次亂聖人畫卦之序，八宮本宮次第乃「確乎不可易」，並釋卜易遊魂歸魂之義。）

== 0046 八宮八卦次第說下（起） ==
（卷首鈐朱印一方，篆文難辨。）「八宮八卦次第說下　玉京山人于濬英著。
乾宮。天變第一爻則為風（姤），二爻變則為山（遯），三爻變則為地（否）……而乾之變盡矣。天一變而為風，故天與風交；風為天之一變，故次與山交；山為天之再變，故次與地交；乾坤之交畢矣。天之與風交，非與風交也，風變天之爻也，天與之交，是以天之爻與之交也……」（釋八宮一爻至五爻變及本宮上交之理。）

== 0047 八宮八卦次第說下（二） ==
「……姤者乾坤之交一爻也；遯者乾坤之交二爻也；否者乾坤之交三爻也；觀者乾坤之交四爻也；剝者乾坤之交五爻也。剝而乾坤之變盡矣。天包地而交，既交則天中虛而（氣）遊于外矣，天中一虛火之象也，故火又與地交，非火與地交也，以既虛之天與地交也……交地既畢而天退身去，不遠（?）……此一交亦非真交也……」（釋遊魂歸魂爻——火遊魂、天（?）歸魂之義。）

== 0048 八宮八卦次第說下（三·乾宮末坤宮） ==
「天遊漸遠于地，則天竟漸復其初，以既虛之天神返其宅，又火與天交之象也，故火天之大有為乾之歸魂。
坤宮。地變第一爻則為雷（復），二爻變則為澤（臨），三爻皆變則天地（泰），坤之變盡矣。地一變而為雷，故先與雷交；再變而為澤，故次與澤交；三變而為天，故與天交……再變故澤又與天交，而坤乾之交畢矣。地之與雷交非與雷交也，雷變地之一爻，此一爻實天之（?）……之二爻也……」

== 0049 八宮八卦次第說下（四·坤宮末離宮起） ==
「地天交泰，乾坤之交得其中者也。天地雷之復、地澤之臨，則坤有餘而乾不足，交之未及者也；及雷天之大壯、澤天之夬，則坤不足而乾有餘，交之已過者也。復也者坤乾之交一爻也，臨也者二爻也，泰也者三爻也，大壯也者四爻也，夬也者五爻也。夬而坤之變盡矣。
一虛水之象也，故水又與天交，非水與天交也，以既虛之地與天交也。水天之需為坤之遊魂；地遊漸遠于天，則地竟漸復其初，以既虛之地神返其宅，又水與地交之象也，故水地之比為坤之歸魂。
離宮。火變第一爻則為山（賁），二爻變則為風（鼎），三爻皆變則為水（未濟），而離之變盡矣。」
（按：坤宮復臨泰大壯夬五世＋需遊魂＋比歸魂，京房坤宮全合；「神返其宅」釋歸魂，語妙。）

== 0050 八宮八卦次第說下（五·離宮） ==
「火一變而為山（賁），故先與山交；再變而為風（鼎），故次與風交；三變而為水（未濟），故次與水交，而離之變畢矣。火之與山交非與山交也，山變火之一爻……火之與風交非與風交也，風變火之二爻……
火水未濟，離坎之交得其中者也。火山之旅、火風之鼎，則離有餘而坎不足，交之未及者也……蒙也者離坎之交四爻也，渙也者五爻也，未濟也者離之變盡矣。」

== 0051 八宮八卦次第說下（六·離宮末坎宮起） ==
「交五爻也。火包水而交既交，則火中虛而（氣）遊於外矣，火中一虛水之象也，故天又與水交，非天與水交也，以既虛之火與水交也，此一交亦非真交也。水既畢而火退，其去不遠，猶未甚離於水耳，故天水之訟為離之遊魂；火遊漸遠於水，則火竟漸復其初，以既虛之火神返其宅，又天與火交之象也，故天火同人為離之歸魂。
坎宮。水變第一爻則為澤（節），二爻變則為雷（屯），三爻皆變則為火（既濟），而坎之變畢矣。水之與澤交非與澤交也，澤變水之一爻，此一爻者實火之一爻（?）；水之與雷交非與雷交也，雷變水之二爻……水之與火交是以水之（一?）爻與火交也……」
（按：離宮賁鼎未濟蒙渙五世＋訟遊魂＋同人歸魂，京房離宮全合；坎宮起。）

== 0052 八宮八卦次第說下（七·坎宮末） ==
「交五爻也……水火既濟，坎離之交得其中者也。水澤之節、水雷之屯，則坎有餘而離不足，交之未及者也；澤火之革、雷火之豐，則坎不足而離有餘，交之已過者也。節也者坎離之交一爻也，屯也者二爻也，既濟也者三爻也，革也者四爻也，豐也者五爻也，豐而坎之變盡矣。水包火而交既交，則水中虛而（氣）遊於外矣，水中一虛地之象也，故地又與火交，非地與火交也，以既虛之水與火交也，此一交亦非真交也。水既畢而坎退，其去不遠，猶未甚離於火耳，故地火之明夷為坎之遊魂；水（火?）遊漸遠於火則漸復其初，以既虛之水神返其宅，又地與水交之象也，故水地之師為坎之歸魂也。」

== 0053 八宮八卦次第說下（八·巽宮） ==
「天與水交之象也，故地水之師為坎之歸魂。
巽宮。風變第一爻則為天（小畜），二爻變則為火（家人），三爻皆變則為雷（益），而巽之變盡矣。風之與天交非與天交也，天變風之一爻；風之與火交非與火交也，火變風之二爻；風之與雷交是以風之一爻與雷交也……天與風交是以風之二爻（?）與天交也……風雷益，巽震之交得其中者也。風天之小畜、風火之家人，則巽有餘而（震不足）……」
（按：坎宮既濟革豐五世＋明夷遊魂＋師歸魂，京房坎宮全合；巽宮小畜家人益三世起。）

== 0054 八宮八卦次第說下（九·巽宮末震宮起） ==
「而震不足，交之未及者也。天雷無妄、火雷噬嗑，則巽不足而震有餘，交之已過者也。小畜也者巽震之交一爻也，家人也者二爻也，益也者三爻也，無妄也者四爻也，噬嗑也者五爻也。風包雷而交既交，則風中虛而（氣）遊於外矣，風中一虛山之象也，故山又與雷交，非山與雷交也，以既虛之風與雷交也……交雷既畢而風退，其去不遠，猶未甚離于雷耳，故山雷順（漸?）為巽之遊魂；風遊漸遠于雷則漸復其初，以既虛之風神返其宅，又山與風交之象也，故山風之蠱為巽之歸魂。
震宮。雷變第一爻則為地（豫），二爻變則為水（解），三爻皆變則為風（恆），而震之變盡矣。」
（按：巽宮小畜家人益無妄噬嗑五世＋漸遊魂＋蠱歸魂，京房巽宮全合。）

== 0055 八宮八卦次第說下（十·震宮） ==
「雷之與地交非與地交也，地變雷之一爻，此一爻者實風之一爻（?）；雷之與水交非與水交也，水變雷之二爻……雷風恆，震巽之交得其中者也。雷地之豫、雷水之解，則震有餘而巽不足，交之未及者也；地風之升、水風之井，則震不足而巽有餘，交之已過者也。豫也者震巽之交一爻也，解也者二爻也，恆也者三爻也，升也者四爻也，井也者五爻也……」
（按：震宮豫解恆升井五世；游魂當為澤風大過、歸魂雷澤隨，俟下葉。）

== 0056 八宮八卦次第說下（十一·震宮末艮宮起） ==
「故澤又與風交，非澤與風交也，以既虛之雷與風交也，此一交亦非真交也。交風既畢而雷退，其去不遠，猶未甚離于風耳，故澤雷大過為震之遊魂；雷遊漸遠于風則漸復其初，以既虛之雷神返其宅，又澤與雷交之象也，故澤雷隨為震之歸魂。
艮宮。山變第一爻則為火（賁），二爻變則為天（大畜），三爻皆變則為澤（損），而艮之變畫（盡）矣。」

== 0057 八宮八卦次第說下（十二·艮宮末兌宮起） ==
「火之與澤交是以山之二爻與澤交也。天之與澤交非與澤交也……山澤損，艮兌之交得其中者也。山火賁、山大畜，則艮有餘而兌不足，交之未及者也；火澤睽、天澤履，則艮不足而兌有餘，交之已過者也。賁也者艮兌之交一爻也，大畜也者二爻也，損也者三爻也，睽也者四爻也，履也者五爻也。山包澤而交既交，則山中虛而（氣）遊於外矣，山中一虛風之象也，故風又與澤交，非風與澤交也，以既虛之山與澤交也，此一交亦非真交也。交澤既畢而山退，其去不遠，猶未甚離于澤耳，故風澤中孚為艮之遊魂；山遊漸遠于澤則漸復其初，以既虛之山神返其宅，又風與山交之象也，故風山漸為艮之歸魂。
兌宮（起，下葉）」
（按：艮宮賁大畜損睽履五世＋中孚遊魂＋漸歸魂，京房艮宮全合。八宮說下至此僅餘兌宮。）

== 0058 八宮八卦次第說下（十三·兌宮） ==
「澤變第一爻則為水（困），二爻變則為地（萃），三爻皆變則為山（咸），而兌之變畫（盡）矣。澤之與水交非與水交也，水變澤之一爻，此一爻者實山之一爻（?）……澤山咸，兌艮之交得其中者也。澤水困、澤地萃，則兌有餘而艮不足，交之未及者也；水山蹇、地山謙，則兌不足而艮有餘，交之已過者也。」

== 0059 八宮八卦次第說下（十四·兌宮末）＋總論 ==
「困也者兌艮之交一爻也，萃也者二爻也，咸也者三爻也，蹇也者四爻也，謙也者五爻也。澤包山而交既交則澤中虛而（氣）遊於外矣，雷之象也，故雷又與山交……以既虛之澤與山交也，此一交亦非真交也。交山既畢而澤退，其去不遠猶未甚離（?）。澤遊漸遠于山則漸復其初，以既虛之澤神返其宅，又雷與澤交（之象也），故澤雷歸妹為兌之歸魂。
總論。陽不交陰萬物不生，陰不交陽萬物不成，陰陽不交萬物不寧。猶天除（升降?）地，陰陽互易而萬物生焉、成焉、亨焉。大哉易也，其天地萬物之樞乎！天覆地載，乾坤之交也；日往月來，離坎之交也；風雷旋轉，巽震之交也；山澤融結，艮兌之交也。其在人也，有父子之交、君臣之交、夫婦之交、昆弟之交……」
（按：兌宮困萃咸蹇謙五世＋歸妹歸魂，京房兌宮全合；八宮說下八宮俱畢；「總論」即目次卷五「又總論十一」之首——以交樞論貫天人倫。）

== 0060 總論（末） ==
「有朋友之交。天地之數止於五，故爻之交至五而止；人之交亦至五而止。交止於五，不盡其一（?），再交則本體亡矣。交一以至五，爻皆交之正者也；遊歸之交，爻變者也。爻既不得不遊，勢之所不容已也；遊則不能不歸，情之所不容己也。其一遊也又特（待?）而不貪不變，所以善其交也；其一歸也，由散而聚，復命歸根，所以全其天也。天地之所以萬古常交而不缺者，由此道也。五進而後極，其進也漸，進以禮也；一遊而即歸，其退也速，退以義也。此天地自然之道也。知進而不知退者，愚不肖之所以不及也；知退而不知進者，賢智之所以過也。其去遁（遁?）也遠矣。然微而必顯，盛則必衰，交一則酹（爵?）一爻，不如不交之為愈也。然微而必顯、盛則必衰者，天地之定數也；酌盈濟虛，衰多益寡，天地之大公也。持不交之說者，私而已矣，非天地之道也。」
（按：「天地之數止於五故爻之交至五而止」——著录摘句之所本；進退之義「進以禮退以義」與著录「進而知退者賢智之所以通也」相應（文字小異）。）

== 0061 附逆歸說（起）＋識語 ==
「右說本丁卯之夏既成前說之後，復將乾宮卦作遞變，則觀之若（?）自然之次第者。及遍閱八宮又無不皆合其義，與前說迥異而不相背。乃知聖人之精蘊，每未揭於天地者多矣。非是思欲復成一說，而舉筆輒罷者屢焉。戊辰夏，因吾友月川之家，忽得一說，屬（?）焉。然數歲，今舊稿忽得，反覆再玩，若有不愜者。鄙意又推其說如此，視舊說稍加密焉。嗚呼！予方前說之既成，自以為若無餘蘊矣，今又推其說如此，安知後之視今不猶今之視昔乎！聖人之精愈揭愈妙，人心之靈愈用愈出，吾又安能量後此之所至。雖戊辰之去今歲已五六年矣，五六年之中不能推而今始推之，豈亦有定數而能以自主者耶！因誌其成說之由，以見至道之妙，非苦心極力不能得，然亦非皆心力之所能必得也。嗚乎難矣。昔乾隆十八年歲次癸酉夏五月之吉　濡陽後學于濬英文識於福元堂」
（按：**附逆歸說識語紀年乾隆癸酉 1753**——並追述丁卯成前說、戊辰 1748 得新說於月川家；紀年鏈完整：丁卯 1747（八宮圖說上）→戊辰 1748（得逆歸說）→辛未 1751（制圖、跋）→癸酉 1753（附逆歸說、題造化說）→甲戌 1754（序）。）

== 0069 附逆歸說（末） ==
「右八宮相交圖各一，二宮合圖四，四宮合圓二，六十四卦總圓圖一。方一相交之義說中已具，茲復按方位圖之，而遊歸之義更自昭然。二宮合圖與四宮合圖無甚深意，不過漸次合來以為六十四卦總圖之漸耳。其圖圓順逆往來縱橫交互，玩其文理脈絡，正視之有八面皆申之象焉；微斜視之，有八面皆井之象焉。六十四卦分佈其上，外六而中八（?），居重疊輕重之象也。六之數圓，八之數方，圓八方之外圓而內方，外圓內靜之象也。圓聚於中宮則方居中卦，豈非天包萬有之象乎！正爻居中又豈非得天地中和之氣乎！反覆玩之其妙無窮，誠天地自然結構之理數也。至方圖除八卦相週而外，其為方者縱橫凡三，文理極簡點亦有八面皆申之（象）……」
（按：附逆歸說全卷以圖為主、圖說相發，「外圓內方」「天包萬有」諸象為其圖論之綱。）
