== 0001 手太陰肺及經圖 ==
題「手太陰肺及經圖」。經文（朱筆句讀，可讀）：
「肺重三斤三兩，六葉兩耳，四垂如蓋，附著於脊第三椎，中有二十四孔，列諸臟之華蓋。人有二喉：前為喉嚨，通于五臟，主氣出入；後為咽喉，主納水穀，通于六府。〔靈云：咽喉者氣之所致上下也；後喉者水穀之道也。〕」
「肺者相傅之官，治節出焉。肺者氣之本，魄之處也，其華在毛，其充在皮，為陽中之少陰，又為太陰，通乎秋氣。肺藏氣，舍魄。肺之合皮也，其榮毛也，其主心也。西方。」
（圖）肺系一具：上為氣管九節（標「肺系」「九節」），下分六葉兩耳（標「六葉」「兩耳」）。鈐國會圖書館藏書印。
（按：經文輯自《素問·靈蘭秘典論》《六節藏象論》《五臟生成》《陰陽應象大論》及《難經》四十二難肺重說；「陽中之少陰」從《靈樞》肺屬太陰之文有出入，原鈔如是。）

== 0002 肺经文（續） ==
「生燥，生金，生辛，生肺」「肺主鼻。在色為白，在音為商，在聲為哭，在變動為咳，在竅為鼻，在志為憂，憂傷肺」。
「肺脈氣流經，氣歸於肺，朝百脈，輸精於皮毛。脾氣散精，上歸於肺，通調水道，下輸膀胱。氣歸於權衡，權衡以平，氣口成寸，以決死生。」「胃為五臟六腑之海，其清氣上注於肺，氣從太陰而行之。手太陰獨受陰之清。其清者上走空竅，其濁者下行諸經。諸氣者皆屬於肺。」
「肺苦氣上逆，急食苦以泄之。肺欲收，急食酸以收之。酸補之，辛瀉之。」
（按：輯自《素問》陰陽應象大論、五藏生成、經脈別論、藏氣法時論諸篇，朱筆句讀。）

== 0003 肺经论说（續） ==
「說曰：肺為一身元氣之主，故其體在主持諸氣，而其用在治節。治節能使諸臟腑之氣出入上下循環各由其道而無太過不及，是治且節也，即所謂權衡也。然本氣屬燥金，畏寒惡火。以其合在皮毛而主鼻，風寒自太陽侵之；受胃之清營時若飲冷，自陽明傳之。此風寒宜表散、飲冷宜溫也。其性既喜潤惡火，則腎虛水虧、肝逆雷起，并厥陽五志之火皆得上逆而犯之，故與風寒之蔽塞皆苦氣上逆。是以為肺苦而必以苦泄之者，肺實也；以酸收之者，肺虛也。肺之道在是矣。」
（按：此頁起為纂者發揮之「說」，非純輯經文——融匯經義而以虛實分治，體例近《醫宗必讀》輯說。）

== 0005 手太陰兮穴歌（肺經穴歌）★ ==
題「手太陰兮穴歌」。歌訣（可讀）：
「太陰肺兮出中府，雲門之下一寸許。雲門璇璣傍六寸，巨骨之下二骨數。天府腋下三寸求，俠白肘下五寸主。尺澤肘中約紋論，孔最腕上七寸取。列缺腕側一寸半，經渠寸口陷中是。太淵掌後橫紋頭，魚際節後散脈舉。少商大指端內側，此穴若鍼疾減愈。」

== 0006 肺經循行發揮論 ==
「（營氣）總布之十二經，以其精專者行於經隧，是以清營之氣通行隨道，必從手太陰肺始而終於厥陰肝，循環陰陽內外上下，以是為一周，終晝夜五十周於身。故循環者必始太陰，非以平旦寅時出太陰也。其經既起中焦，而以表裏氣通，故下絡大腸；既絡大腸，乃始從肺系橫出腋下，循臑內行少陰心主之前者，少陰心胞之行在臑內廉中行，此出臑內上廉，故行其前也。由是直入寸口，上魚際，出大指之端。而其支者復從腕後過（?）合谷，直出次指，以注手陽明之端。」
「乃臟腑之井滎腧經原合六俞，皆從下而上。」
（按：循行錄《靈樞·經脈》肺經文而以滑壽《十四經發揮》說貫之；「五十周於身」「平旦寅時」辨營氣循環之起，皆發揮篇語。）

== 0009 大腸經文・說 ==
「（膝下）外三里下三寸為巨虛上廉，復下上廉三寸為巨虛下廉。大腸屬上，小腸屬下，足陽明胃脈也。大腸小腸皆屬於胃。」「手太陽獨受陽之濁。」
「說曰：大腸既屬傳道，祗何名為器而待用於土？脾因其傳道屬陽明胃之下流，而獨受陽明之濁，故其合穴本見於陽明經之巨虛上廉，於肺金無涉。特以經隧上下者肺所絡，故亦通乎肺氣，其不得為陽中之少陰主乎秋令矣。要之亦得為陽明經而與胃經接者，亦胃陽明之流溢，斯共一氣耳。今言陽明必二者兼舉，論病亦誤之甚矣。」
（按：說辨大腸合穴巨虛上廉在胃經之理——傳道屬胃之下流故受陽明之濁；末譏「陽明必兼舉大小腸」之誤，是纂者考辨之筆。）

== 0012 大腸經循行論 ==
「溜上曲池，肘臂之外上廉，直上肩髃而上於柱骨之會上。入缺盆絡肺，下膈屬大腸，此內行之絡也。其支復上貫頰，挾口上挾鼻孔，以接於胃陽明。然其與肺之臂內上廉表裏並行，故表裏於肺也。」

== 0013 大腸經流注・說 ==
流注：「大腸上合於手陽明，出商陽為井（金），溜於二間為滎，注於三間為腧，過於合谷為原，行於陽谿為經，入於曲池為合。」「注於三間為腧，過於合谷為原，行於陽谿為經，入於扶突偏歷也（?）」。
「說曰：大腸之陽明為胃陽明經氣之流溢，傳道於此也。內與肺合絡，故得沾肺氣而為金。然其體屬胃，既不為陽明土之正，又豈為太陰金之正耶？說者為庚金耶（?）。而妻其肺，夫肺為相傅之官，陽中之太陰，乃為大腸妻耶？紕繆可笑，有論以譬之矣。此經起次指端，入合谷，從溫（?）。」
（按：說辨大腸經五行屬性——「庚金之正」舊說與肺表裏之實，纂者斥「妻其肺」之紕繆，考辨之風一貫。）

== 0015 心經論說 ==
「前曰廣明。說曰：心為君，主神明出焉。所謂神明者，通變不測；明者虛靈不昧，宜居廣明以建極者，太陽之主，而通乎夏氣。是以太陽為君為父為經為三陽，然又主表者，以神之所照，陽氣從之，為衛外而為固也。故凡邪與氣從外來者，雖先動毫毛，必神者先覺，故心部於表也。然以火為位而承以養者，陰精也。陰精腎水也，於太衍（?）上貢之以養心；苦腎精絕貢，則心火自焚矣。故養心存神者必在寡欲，此取坎填離之道也。」
（按：說以廣明建極、心部於表釋「心部於表」經文；末拈「取坎填離」丹家語養心，是儒醫合流之筆。）

== 0017 心經穴歌・獨無俞論 ==
穴歌（題「兮寸歌」，承上葉「手少陰兮」）：「少陰心起極泉中，腋下筋間脈入胸。青靈肘上三寸取，少海肘後端五分。靈道掌後一寸半，通里腕後一寸同。陰郄腕後方半寸，神門掌後兌骨隆。少府節後勞宮直，小指內側取少衝。」
論：「手少陰之脈獨無腧。歧伯曰：少陰心脈也。五臟六腑之大主，精神之所舍，其臟堅固，邪弗能容，故諸邪之在於心皆在心之絡。絡者，心主之脈也，故獨無腧焉。」「若其有病，其外經病而臟不病，若治經病則獨取其經於掌後銳（?）。」
（按：穴歌九穴承極泉至少衝；「獨無腧」用《難經》二十五難（?）文——心經無五輸之辨，惟取神門。）

== 0018 心經循行論 ==
「骨之端，其餘脈出入屈折，其行之疾徐，皆如手少陰心主之脈行也。手少陰之本在銳骨之端，標在背腧，即心腧。」「說曰：手少陰獨無腧，謂歧伯述井滎腧經合五腧於手心主之經而不取少陰也。以心藏神，其臟氣堅而邪不能入，即有病於經者，獨取經之神門，要以經氣之本於此取之也。其臟並無根結者，神明之域，正位於廣明，即作極建於極於此，而非若他臟之有原起也。標在背腧而不言取者，極（?）於此而入太陽之部，特神明氣之出入耳。心系二支：一支上挾咽繫目系；一支出肺下出腋，行臂內之下廉出。」
（按：根結說（標本根結）——心經「本在銳骨之端標在背腧」，無根結以神明無形；循行文出《靈樞·經脈》。）

== 0021 小腸經文・說 ==
「為壯臟（?），小腸為之使。」「說曰：小腸受盛之官，化物出焉。所以化物者，以其府末離中焦相火之部，承陽明之熱壯，故化物於此而出。然既心絡與之合，則火就燥，是以為之使。心不受病而病每留於小腸：故鬲（?）不便，上為口糜，下為便血溺赤莖中痛，皆心火之下流也。若小腸自病，則仍歸陽明之巨虛下廉，不取本經也。至此以為丙火謬矣。」
（按：「心不受病而病每留於小腸」承 0017 獨無腧之義；末句辨小腸丙火屬性之舊說為謬——纂者考辨之筆再現。）

== 0024 小腸經循行論 ==

== 0039 三焦無形之辨（文）★考辨 ==

「心包起自天池間，乳後一寸腑下三。天泉曲腋下二寸，曲澤屈肘陷中央。郄門去腕方五寸，間使腕後三寸量。內關去腕止二寸，大陵掌後兩筋間。勞宮屈中名指取，中指之末中衝良。」「心主出於中衝為井（木），溜於勞宮為滎。注於大陵為腧，行於間使為經，入於曲澤為合。」「手心主之本在掌後兩筋之間二寸中，標在腋下三寸也。標：內關；本：天池。」
（按：心包經穴歌九穴；流注中衝井木；根結「本在掌後兩筋間標在腋下」出《靈樞·衛氣》。）

== 0049 膀胱經論（文）★考辨 ==
「陽在五陰之上，於卦為剝，故太陽高而主寒水也。若人身則太陽根於少陰，起於至陰，是與太陽為主者唯腎耳。然太陽經者腎藏，陽必歸陽，故借納於膀胱也。其寶（?）應大腸寒水者唯腎得主之，膀胱無與焉。蓋膀胱者州都之官，其地不接太倉廣明，其用不得與於三焦。俟三焦之化，而後能提吸水道而出，是膀胱無能焉而必待三焦之氣化與肺之通調而後能出也。夫如是，其府豈能主持太陽？**膀胱主太陽者更謬也。**」
（按：**纂者再斥舊說**——州都之官無氣化之能，津液之出待三焦化與肺通調，「膀胱主太陽」為謬；與 0021「丙火謬矣」同一考辨風格，本冊說論之特色。）

== 0051 足太陽兮寸歌（膀胱經穴歌・上）★ ==
「足太陽兮寸歌。足太陽膀胱之經，目內眥始睛明。眉頭陷中攢竹取，曲差髮際上五分。五處髮上一寸是，承光髮上二寸半。通天絡卻玉枕穴，相去寸五調勻看。玉枕夾腦一寸三，天柱項後髮際中，大筋外廉陷中獻（?）。自此夾脊開寸五：第一大杼二風門，三椎肺俞厥陰四。心俞五椎之下論，膈七肝九十膽俞。十一脾俞十二胃，十三三焦十四腎。大腸十六小（腸）十八，膀胱十九中膂內俞二十椎。白環二十一。已上諸穴可排之。」
（按：**背俞歌訣**——「一大杼二風門三椎肺俞厥陰四心俞五膈七肝九十膽十一脾十二胃十三三焦十四腎」，背俞定位之經典韻語，與《針灸大成》同。）

== 0052 膀胱經穴歌（下）★ ==

（按：膀胱經穴歌下篇——附分至秩邊背部二行三行十二對（?），承扶至承山腿部諸穴；「十二髎空」即八髎加兩髎（?）之數。）

== 0053 膀胱經流注 ==

== 0054 膀胱經說（文） ==
「說曰：足太陽為巨陽，為諸陽主氣，故其地分闊，上接全顛。背列四行，凡五臟六腑之俞通貫於是。故臟腑各俞之外，復列魄戶、神堂、魂門、意舍、志室，為五臟神之所寓。其根於至陰，入於天柱、飛揚，為其出入之盛也。陽之精華大（?）於神明，神明之出入莫大於目，故目為命門而太陽結於此。要以心為太陽之主，而心之精聚於此也。又有膀胱之（?）……」
（按：背俞四行之解——臟腑俞之外復列魄戶神堂魂門意舍志室為**五臟神之所寓**，是神堂魂門意舍志室諸穴命名之義理；「目為命門」出《靈樞·衛氣》？（待考）。）
