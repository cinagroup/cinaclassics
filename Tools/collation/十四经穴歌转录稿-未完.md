== 0001 手太陰肺及經圖 ==
題「手太陰肺及經圖」。經文（朱筆句讀，可讀）：
「肺重三斤三兩，六葉兩耳，四垂如蓋，附著於脊第三椎，中有二十四孔，列諸臟之華蓋。人有二喉：前為喉嚨，通于五臟，主氣出入；後為咽喉，主納水穀，通于六府。〔靈云：咽喉者氣之所致上下也；後喉者水穀之道也。〕」
「肺者相傅之官，治節出焉。肺者氣之本，魄之處也，其華在毛，其充在皮，為陽中之少陰，又為太陰，通乎秋氣。肺藏氣，舍魄。肺之合皮也，其榮毛也，其主心也。西方。」
（圖）肺系一具：上為氣管九節（標「肺系」「九節」），下分六葉兩耳（標「六葉」「兩耳」）。鈐國會圖書館藏書印。
（按：經文輯自《素問·靈蘭秘典論》《六節藏象論》《五臟生成》《陰陽應象大論》及《難經》四十二難肺重說；「陽中之少陰」從《靈樞》肺屬太陰之文有出入，原鈔如是。）

== 0002 肺经文（續） ==
「生燥，生金，生辛，生肺」「肺主鼻。在色為白，在音為商，在聲為哭，在變動為咳，在竅為鼻，在志為憂，憂傷肺」。
「肺脈氣流經，氣歸於肺，朝百脈，輸精於皮毛。脾氣散精，上歸於肺，通調水道，下輸膀胱。氣歸於權衡，權衡以平，氣口成寸，以決死生。」「胃為五臟六腑之海，其清氣上注於肺，氣從太陰而行之。手太陰獨受陰之清。其清者上走空竅，其濁者下行諸經。諸氣者皆屬於肺。」
「肺苦氣上逆，急食苦以泄之。肺欲收，急食酸以收之。酸補之，辛瀉之。」
（按：輯自《素問》陰陽應象大論、五藏生成、經脈別論、藏氣法時論諸篇，朱筆句讀。）

== 0003 肺经论说（續） ==
「說曰：肺為一身元氣之主，故其體在主持諸氣，而其用在治節。治節能使諸臟腑之氣出入上下循環各由其道而無太過不及，是治且節也，即所謂權衡也。然本氣屬燥金，畏寒惡火。以其合在皮毛而主鼻，風寒自太陽侵之；受胃之清營時若飲冷，自陽明傳之。此風寒宜表散、飲冷宜溫也。其性既喜潤惡火，則腎虛水虧、肝逆雷起，并厥陽五志之火皆得上逆而犯之，故與風寒之蔽塞皆苦氣上逆。是以為肺苦而必以苦泄之者，肺實也；以酸收之者，肺虛也。肺之道在是矣。」
（按：此頁起為纂者發揮之「說」，非純輯經文——融匯經義而以虛實分治，體例近《醫宗必讀》輯說。）

== 0005 手太陰兮穴歌（肺經穴歌）★ ==
題「手太陰兮穴歌」。歌訣（可讀）：
「太陰肺兮出中府，雲門之下一寸許。雲門璇璣傍六寸，巨骨之下二骨數。天府腋下三寸求，俠白肘下五寸主。尺澤肘中約紋論，孔最腕上七寸取。列缺腕側一寸半，經渠寸口陷中是。太淵掌後橫紋頭，魚際節後散脈舉。少商大指端內側，此穴若鍼疾減愈。」
旁注五輸流注：「少商為井（木）」「溜於魚際為滎」「注於太淵為腧」「行於經渠為經」「入於尺澤為合」〔小字五行注待細核〕。
（按：**此即書名「穴歌」之體**——承滑壽《十四經發揮》穴歌系統，逐穴詠位次；旁注五輸流注（井滎腧經合）配五行，是穴歌與流注說合鈔之本。）

== 0006 肺經循行發揮論 ==
「（營氣）總布之十二經，以其精專者行於經隧，是以清營之氣通行隨道，必從手太陰肺始而終於厥陰肝，循環陰陽內外上下，以是為一周，終晝夜五十周於身。故循環者必始太陰，非以平旦寅時出太陰也。其經既起中焦，而以表裏氣通，故下絡大腸；既絡大腸，乃始從肺系橫出腋下，循臑內行少陰心主之前者，少陰心胞之行在臑內廉中行，此出臑內上廉，故行其前也。由是直入寸口，上魚際，出大指之端。而其支者復從腕後過（?）合谷，直出次指，以注手陽明之端。」
「乃臟腑之井滎腧經原合六俞，皆從下而上。」
（按：循行錄《靈樞·經脈》肺經文而以滑壽《十四經發揮》說貫之；「五十周於身」「平旦寅時」辨營氣循環之起，皆發揮篇語。）
