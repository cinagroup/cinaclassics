「凡人之相者，以頭為主，以眼為權。頭則五行之首，眼則形相之先。觀頭之方圓，察眼之黑白；頂圓而必貴，目善而必慈。精神而性必剛，睛露而心必毒。斜觀者必懷嫉妬，低視者處性陰疑。面促青藍多遭（?）否，紅黃不改必遇榮昌。黑白色侵憂橫疾病，紫（?）色福祿加身。要知剋子害紀，必是眼下無肉。卧蠶平起，後嗣相隨。眉中旋毛，兄弟必衆。眉橫一字存義峻（?）。人要知姦詐孤貧，看他鼻頭尖薄。官高職顯，准頭齊促截（?）。簡用苦中年，定是風門昂露。齒結喉相中大忌：文夫則骨肉分離，婦人則損夫（?）子。口尖唇薄，此人多是多非。印上雜文，受主遭刑（?）。口角兩垂向下（?）。」
（按：總論綱目——頭為主、眼為權；目善必慈、睛露心毒；眼下無肉剋子、卧蠶平起後嗣隨、眉中旋毛兄弟眾、鼻頭尖薄姦詐孤貧、齒結喉大忌、口尖唇薄多是非、印上雜文遭刑——皆通行相法常談，此冊總論與《神相全編》總論系同源。個別字（?）待复核。）

== 13L 相形・五形論（文） ==
篇題：「相形」。正文（幾可全讀）：
「夫人之生，精合而後神生，神生而後形全。是知金〔?〕於外者，為之形。〔?〕之在人，有金木水火土之象，有飛禽走獸之倫。金不嫌方，木不嫌瘦，水不嫌肥，火不嫌尖，土不嫌濁。似金得金，剛毅深（?）；似木得木，貲財足；似水得水，文學貴；似火得火，機（?）大；似土得土，厚庫（?）。故豐厚嚴謹者不富則貴，薄〔?〕輕躁者不貧則夭。女子欲其和媚，形欲嚴整。能若此者，其大貴也。」
歌訣：「金形方：部位要中正，金形人人格（?），三停又帶方，自是有名揚。」「木形昂藏：稜（?）形瘦骨，秀氣生眉眼（肩?），凜（?）更脩長，復知晚景光。」
（按：五行形局總論——「似金得金剛毅深，似木得木貲財足，似水得水文學貴」云云，即《麻衣》五行正形歌之祖本；飛禽走獸之倫啟下文獸形相。）

== 13R 八宮分・推五形運數 ==
宮分：「陰陽為男女宮」「懸壁位為奴婢宮」「魚尾位為妻妾宮」「眉目位為官祿宮」——「已上面部總八宮分」。
推五形運數：「推五形運數：金敷四（?），木數三，水數一，火數二，土數五。」「金形方，木形瘦，水形肥，火形尖，土形厚。」
行限：「金形：四歲行運，二十六交中限，四十六入末限」「木形：三歲行運，二十七交中限，三十三交末限」「水形：一歲行運，二十五交中限，四十二交末限」「火形：二歲行運，二十八交中限，四十八交末限」「土形：五歲行運，二十九交中限，四十九交末限」。
（按：**五形起運交限之數**——依五行生成數定起運歲（水一火二木三金四土五），中限、末限交脫各異，此為相法行限之骨幹數表；八宮分補 12L 宮分之未備。皆與《神相全編》行限篇同式。）

== 15L 相神（文） ==
篇題：「相神」。正文（幾可全讀）：
「夫人形以養血，血以養氣，氣以養神。欲深不欲淺：深則智深，淺則智淺。用則形於眼，收則合於心。近觀有速（?），望有威，瞻視有力，臥易醒，此乃神之全也。」
神之諸相：「神遊於眼，富時也」「神處於心，寐時也」「神昏如睡，無盛也」「神困如睡，無盛也」「瞧（?）而易覺，神全也」「神殺照人，文俊也主貴」「神怯如驚，主夭」「神流如淫，主奸盜」「神用如弱，主疾病」
「詩曰：神居形內不可見。氣壯血和則安固。血枯氣散神先奔。」
（按：形血氣神四層遞養之說，與《神相全編·相神》同源；神「用則形於眼，收則合於心」數語為眼神觀察法之綱。）

== 15R 相神詩・聽聲（文） ==
相神詩：「英標精彩心神爽，氣血調和神不昏。神之清濁與形表，能定貴賤最難論。」
篇題：「聽聲」。正文（幾可全讀）：
「夫人之有聲，猶鐘鼓之響，器大則聲宏，小則聲短。神清而氣和則聲溫潤而圓暢也；神濁而氣促則聲焦急而輕漵也。故貴人之聲遠，小人之聲近。或乾溫而不均謂之羅網聲，大小不均謂之雌雄聲。或先遲而後急，或先急而後遲，或聲未止氣先絕，或聲未舉而色先變，皆賤者之相也。夫人稟五行則其聲〔?〕五行之象：故土音沉厚、木音高暢、火音焦烈、金音和潤、水音圓急。聲輕者處事無斷，聲破者作事無成，聲濁者謀運不發，聲低者魯鈍無文，聲硬者姿性淺（?）。」
（按：**聽聲一篇幾全**——器大聲宏、羅網聲雌雄聲、五行五音（土沉厚木高暢火焦烈金和潤水圓急）、聲輕破濁低硬五病，與《神相全編·相聲》篇同源而更簡淨。相序至此：形→神→聲，下當繼以色。）
